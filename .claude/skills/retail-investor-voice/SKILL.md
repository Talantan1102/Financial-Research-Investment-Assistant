# 散户之声 — 让台词像真实中国股民说话

## Overview

核心原则一句话:**越通顺越像假**。真实散户打字是短、断、错、燥、黏(黑话)的即时流;AI 的天性是写完整通顺的句子——写散户台词时必须主动对抗这个天性。

本 skill 的语料底座是从股吧/淘股吧/集思录/B站等扒来的 90+ 条真人原话(经真伪批判剔除段子手金句),见 `references/corpus.md`。

## When to Use

- 为记忆评估脚本(`backend/eval/memory_dialogue/scripts/`)写用户台词
- 任何需要模拟散户/股民说话的场合(测试数据、demo 对话)
- 审校已写台词:判断"像不像真人"

不适用:写助手(AI 侧)台词、写书面分析内容。

## 生成流程(每条台词都走一遍)

1. **查语料**:打开 `references/corpus.md`,找到对应场景(问操作/问行情/晒亏求安慰/表达后悔/质疑反驳/重提旧事/黑话闲聊),读该场景的真人原话找语感
2. **挑骨架填槽**:优先用语料里的句式骨架(从真原话抽象,带源句),填入脚本需要的标的/价格/观点
3. **按长度分布采样**:极短(3-8字)约三成、一句话约四成、一两句带黑话约两成、流水账长段约一成(只用于忏悔晒亏/阴谋论两种情绪极值)
4. **注入真人指纹**(每条至少命中两项):语气词收尾(嘛/么/不/啦/呀/啊/吧)、称呼(老师/大佬/兄弟们)、黑话(见语料词典)、错别字(同音:张=涨/再看把=再看吧/的本=成本)、标点燥感(`!!!` `。。。。。。` 双问号)
   - **错别字频率单独考核**(实测最易被绕开):每 5-8 条台词至少注入 1 处同音/手滑错字——语气词和黑话满足"两项"后你会想跳过错别字,不许跳
5. **自检两道**:(甲)读出声——你真会这么跟人说话吗?(乙)过下面的失败指纹表,命中任何一条就重写

## 失败指纹 → 修法(基线实测,AI 不带 skill 必犯)

| AI 写出来的 | 真散户会说的 | 病根 |
|---|---|---|
| "核心逻辑就是高端白酒有提价权,每年提个价业绩就稳了,长期拿着肯定没错" | "白酒我就认提价权这一条,拿三年" | 完整逻辑链;散户不解释自己,理由最多半句 |
| "渠道有壁垒、品牌护城河深" | "这玩意儿闭着眼拿" | 研报词(护城河/景气度/壁垒/确定性)混进口语 |
| "不悲观但也不敢加仓" | "不敢动,先看看" | 对仗工整 = 段子手指纹 |
| "是直接清掉,还是先减一部分仓位降降风险?" | "要不要先出一半?" | 像顾问列选项;散户甩半句 |
| "这跟我之前想的不太一样啊" | "动销这么差?我人麻了" | 委婉书面;散户直接情绪化 |
| 8 条台词零错别字零燥标点 | 每几条就有一处同音错字或 `!!!` | 太干净 = 假 |

## 三条分布纪律(语料实测,违反一眼假)

- **「更正前言」别正式化**:真散户几乎不回头郑重改口(语料里自然样本≈0)。改观点要走"重提旧事顺带改"——"上次说的白酒我又想了想,三年太满了"——而不是"我更正一下之前的观点"
- **短为主**:连续多条都是完整长句 = 假。该惜字如金时就"止盈不""亏麻了"
- **涨跌幅说"几个点"**,不说百分比;成本说"XX的本",不说"成本价为XX元"

## Red Flags — 命中即重写

- 一段台词里所有句子主谓宾齐全
- 出现:综上所述 / 值得注意的是 / 总的来说 / 确定性 / 景气度 / 护城河 / 性价比凸显
- 三句以上排比或对仗
- 正式更正句式("我想修正一下我之前的看法")
- 整段零语气词、零黑话、零错别字、零燥标点(四项全无必假)

## Common Mistakes

| 借口 | 现实 |
|---|---|
| "评估脚本要可读,台词得写清楚" | 可读性是断言字段的事;台词字段只对"真"负责。抽取器就该在真实噪声里干活 |
| "这个场景需要用户把观点表达完整" | 真散户表达观点就是半句+黑话。完整观点让助手复述确认去(对话脚本里助手侧台词干这个) |
| "错别字会影响测试稳定性" | 错别字注入在用户台词,断言基于数据库状态和助手回答——互不干扰;且这恰是抽取器该扛住的真实输入 |
| "语气词加多了显得轻浮" | 语料实测语气词收尾是散户默认形态;一条不加才是异常 |
