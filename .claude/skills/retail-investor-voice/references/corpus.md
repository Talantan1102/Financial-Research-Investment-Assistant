## 二 · 句式骨架(从真原话抽象,槽位用花括号,带源句)

### 问操作
- `{个股}{成本}的本现在{止盈/止损/补仓}不` ← 中国卫星八十的本现在止盈不
- `{个股}明天可以{买入/卖出}吗?` ← 明天可以买入吗?
- `明天开盘{价格}以下{买/卖}得到吗?` ← 明天开盘四十块四毛五以下能买得到吗?
- `老师,{个股}怎么操作` ← 老师,开开怎么操作
- `问一下,{个股}还有{预期/机会}么,目前持有的{时点}怎么操作` ← 问一下,福龙马还有预期么……
- `{板块/个股}有{接回/进场}吗?` ← 有色有接回吗?

### 问行情
- `老师,{个股}为啥不跟板块,怎么看呢?今天{追/接}进去吃面了,还有机会嘛?` ← 老师,东方明珠为啥不跟板块……
- `{称呼},{个股}{走势描述},好像{时机点}不错?` ← 龙兄,人工智能第一波下杀后……
- `{称呼}{板块}全走啦,{个股}{目标}还能看到吗` ← 大佬有色全走啦,紫金一点五万亿还能看到吗
- `大盘跌{是正常的么/好不好/买入还是卖出}` ← 大盘跌是正常的么

### 晒亏求安慰
- `连亏{N}天,亏{哭/麻}了[关灯吃面][关灯吃面][关灯吃面]` ← 连亏五天,亏哭了
- `{N}天亏了几个点啊 这么难受` ← 五天亏了几个点啊 这么难受
- `{时间}谁有我惨… 安慰安慰我…` ← 二月谁有我惨…
- `今天负{金额}!!!{宣泄}。。。。。。我要崩溃了。。。。。。` ← 今天负一万九千二!!!……

### 表达后悔
- `{时点}卖了,认知不够,{时点}又接回来了` ← 前天卖了,认知不够,今天又接回来了
- `今天负{金额}!!!清仓了!!!不玩了!!!{反讽词}。。。。。。` ← 今天负两千!!!……悟道了……
- `这波真的怪我了,前面一直{操作},我本金{额},借了{额},现在全仓在{个股}里面,今天亏了{额}卧槽啊` ← 大唐发电忏悔帖

### 质疑反驳
- `为啥{论据},却还是{动作}{个股}呢?` ← 为啥分析茅台五粮汾酒卖得好,却还是补老窖呢?
- `这{仓位/业绩}是怎么{回事/预测}的,这么{乐观/高}吗` ← 这仓位是怎么回事?
- `A股只剩{个股}了吗?` ← A股只剩泸州老窖了吗?
- `道理我都懂,但是{反驳论据}` ← 道理我都懂,但是医疗白酒……
- `{称呼}你要不看一眼{某物},{打脸事实}` ← 龙哥你要不看一眼你的公众号……

### 重提旧事
- `{称呼},去年这个{形态}上我栽跟头过。{个股}。可以看一下` ← 楼主大大,去年这个分红底上我栽跟头过。洋河股份
- `{旧标的}前车之鉴啊,我{现状},不敢下手` ← 洋河前车之鉴啊……

### 黑话闲聊
- `兄弟们{鼓劲/告别},我先{大仓位}{溜了/进了}哈!{老庄叙事}` ← 兄弟们顶住,我先大仓位溜了哈!
- `{主力动作},大家伙注意了啊` ← 庄家在洗盘子,大家伙注意了啊
- `今天还{不亏/赚}的是{高手/神}` ← 今天还不亏的是高手

## 三 · 语言特征清单(注入指纹弹药库)

### 高频语气词 / 句尾助词
啊、哈、呀、嘛、么、吧、不、啦、呢、诶、哈哈哈哈(苦笑)、卧槽啊
用法:`{问句}+ 吗/么/不/呀` 试探;`{宣泄}+ 啊/哈` 拖音;二选一句尾爱用「不」(止盈不/走不)

### 口头禅 / 套话
- 求救:有没有人告诉我现在怎么办啊、望回复、安慰安慰我、谁有我惨
- 自我合理化:道理我都懂(就是做不到)、认知不够、再熬个三五年
- 喊单戏精:我会给你们机会的、大家伙注意了啊、兄弟们顶住
- 称呼:老师 / 龙兄 / 龙哥 / 大佬 / 楼主大大 / 兄弟(们)/ 哥们 / 阿雄
- 玩梗:听懂掌声、关灯吃面、亏麻了、白干、太刺激了

### 黑话词典
- 成本:本 / 的本
- 套牢:被套 / 埋 / 解套
- 卖亏:割肉 / 卖飞 / 出来了 / 放人
- 赚钱:吃肉 / 吃大肉 / 吃到肉(误写「迟到肉」)
- 死扛:死拿 / 格局
- 加减仓:补仓 / 加满 / 全仓 / 接回 / 全走 / 清仓 / 止盈出 / 保本出
- 庄家叙事:庄 / 老庄 / 主力 / 控盘 / 洗盘(写「洗盘子」)/ 憋大招 / 收割 / 韭菜
- 走势:抄底 / 下杀 / 回踩 / 支撑 / 虚晃一枪 / 滞涨 / 异动 / 拉红 / 水下 / 做T / 上头
- 涨跌幅一律「几个点」,不说百分比
- 情绪态:吃面 / 关灯吃面 / 亏麻了 / 上头
- 脏话谐音:煞比

### 错别字 / 输入习惯(主动注入)
迟到肉(吃到肉)、张(涨)、洗盘子(洗盘)、再看把(再看吧)、控机不住(控制不住)、最高i(手滑带字母)、控住(控制住)
规律:同音 / 形近 / 手滑带余字,不影响互懂

### 标点习惯
- `!!!` 到 `!!!!!`(越激动越多)
- `。。。。。。`(句号点省略号,无力/苦笑)
- `啊???!!!`(破防反问)、双问号求认同
- 标题即全文;无主语无标点;空格随意

### 消息长度分布(按比例采样)
- 极短(3-8字)约三成:亏麻了 / 半个月白干 / 有色有接回吗
- 短句(一句话)约四成:明天可以买入吗 / 中国卫星八十的本现在止盈不
- 中长(一两句带黑话)约两成
- 流水账长段约一成:仅忏悔晒亏 / 阴谋论喊单两种情绪极值

## 五 · 反面教材:被剔除的「假货指纹」

以下被真伪批判剔除,**写台词时长这样 = 翻车**:

| 假货 | 指纹 |
|---|---|
| 一入股市深似海,从此工资是路人! | 套流行句式,对仗工整零口语 |
| 金鱼的记忆只有七秒,股民的更短 | 段子手金句,无即时输入痕迹 |
| 买入没耐心,卖出没决心,等待没信心 | 三段排比押韵,鸡汤格言体 |
| 整个过程无比煎熬,持股体验极其糟糕 | 「无比/极其」书面副词,记者整理腔 |
| 妻离子散,家人不容,有家不能回 | 四字格排比,媒体凝练 |

判别标准:对仗工整 / 起承转合 / 无错别字无语气词的长段落 / 文艺押韵 → 都是加工痕迹。
真货的特征:**短、断、错、燥、黏**。
