# risk-assessment Skill

## 层级位置

**L3 评估决策层** — 回答"好不好/风险多大",把 L1/L2 的事实转成**可决策的打分**。与 `sector-analysis` 并列(前者个股诊断,后者同业对标)。

- **上游依赖**:`market-data`(估值、波动)、`financial-analysis`(负债率、现金流)
- **被下游调用**:`deep-research`(研报"风险提示"段落)
- **侧向依赖**:`sector-analysis` 的行业 PE 均值可作为估值对标基线

## 何时使用

- 用户询问"这只股票风险如何/有多危险"
- 用户询问估值是否偏高(PE/PB 过高)
- 用户询问财务风险(负债、现金流)
- 用户询问波动率/最大回撤
- 用户要风险预警清单

不适用于:纯事实查询 PE 值是多少(用 `market-data`)、跨行业对比(用 `sector-analysis`)。

## 工具清单(5)

| 工具 | 一句话 |
|---|---|
| `assess_stock_risk` | 综合打分(估值+财务+波动,返回 0-100) |
| `assess_valuation_risk` | 估值风险分项(PE/PB,可传行业 PE 对比) |
| `assess_financial_risk` | 财务风险分项(负债率/流动比/速动比) |
| `assess_volatility_risk` | 波动风险分项(年化波动率/最大回撤) |
| `check_risk_warnings` | 风险预警清单(level + type + message) |

完整参数、评分公式、各维度阈值:见 `references/tools.md`。

## 关键约定

- 综合分 0-30 低 / 30-50 中低 / 50-70 中 / 70-85 中高 / 85-100 高
- 估值阈值:PE <15 低 / 15-30 合理 / 30-50 偏高 / >50 极高
- 财务阈值:负债率 <40% 低 / 40-60 中 / 60-80 高 / >80 极高
- 波动阈值(年化):<20% 低 / 20-30 中 / 30-50 高 / >50 极高
