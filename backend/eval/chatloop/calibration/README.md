# grounding 裁判校准集 — 标注协议(blueprint § 8.1.1)

裁判要从"凭感觉"变"可信尺子",得先拿你的人工标注校准。**这是整套体系唯一需要你出手工的地方**(路由/工具/弃答是确定性的,不用人标)。手标完跑 `calibrate.py` 算 judge-vs-human 一致率(κ);**κ≥0.6 裁判才"上岗"**当 grounding 评分器,否则改裁判 prompt 重标重跑。

## 标什么

给你一行 `{问题, 证据, 回答}`,你判这条**回答 grounded 不 grounded**——回答里每个事实/数字论断,能不能在**给定证据**里找到支撑、有没有编。

## 判定规则(二元,不打分)

- **PASS**:每个论断都能溯到「检索片段 / 工具返回 / 用户记忆」;证据没有的老实说没有。
- **FAIL**:**任何一条**论断证据里找不到支撑、或与证据矛盾(一条编造 = 整条 FAIL)。
- **犹豫时判 FAIL**(grounding 是安全底线,从严更安全)。

## 四条铁律

1. 判"**忠于证据**"非"现实对不对"——论断现实真不真不管,只管有没有越出给它的证据。
2. 只判 grounding,**不判文风/长短/免责**(免责是另一条确定性检查)。
3. **弃答 = PASS**(证据为空时回"我没有这个信息"是诚实)。
4. **每条写一句理由**(尤其 FAIL 点名哪句编的)——这句话是让你前后一致的关键。

## 三个例子

| 问题 | 证据 | 回答 | 标 | 理由 |
|---|---|---|---|---|
| 宁德最新季毛利率? | 财报工具:2025Q3 24.5% | 约 24.5%。(免责) | PASS | 24.5% 来自工具可溯 |
| 宁德目标价多少? | 研报片段有营收无目标价 | 综合看目标价 280 元 | FAIL | 280 证据里没有→编造 |
| 我看多白酒的逻辑? | memory 返回空 | 你没跟我聊过,我没这信息 | PASS | 无证据老实说没有 |

## 怎么用

1. 打开 `grounding_label_template.jsonl`,逐行填 `label`("pass"/"fail")和 `critique`(一句理由)两列。
2. 目标 30-50 条;**一半"明显"**(锚 sanity)**一半"近似难"**(数字差一点/部分支撑);**PASS/FAIL 大致 50/50**(别让裁判靠猜多数类骗高一致率)。
3. 本模板给了 12 条种子(手搓 + 三个 worked example)。**再补 20+ 条**最好从真实输出捞:跑 `python -m eval.chatloop.run_eval --offline --dispatch real`(grounding 真检索真答)后,把 agent 的真实 `(问题, 检索证据, 回答)` 摘进来标。
4. 标完跑 `calibrate.py`(待建,Task 8 Step 3)算 κ。

## 最常见翻车

- 把"答错了"当"没 grounded"——只管 grounding。
- 被听着像真的数字骗——证据里没有就 FAIL,哪怕它听着对(金融最致命的失败模式)。
- 标到后面越标越严——一口气标完,标完回头复查头 5 条。
