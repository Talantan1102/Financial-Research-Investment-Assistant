## § 1.2 盈利能力 (Profitability)

**关键指标** (来自 `get_financials`):
- ROE (净资产收益率) = `净利润 / 股东权益均额` — 衡量股东资本回报, 巴菲特首选指标.
- ROA (总资产报酬率) = `净利润 / 总资产均额` — 剔除杠杆放大效应后的真实赚钱能力.
- 毛利率 = `(营业收入 - 营业成本) / 营业收入` — 反映产品定价权 + 成本控制.
- 净利率 = `净利润 / 营业收入` — 剔除费用 / 税后的最终赚钱能力.
- 净利润 yoy = `(本期净利润 - 去年同期) / 去年同期` (派生字段, `GetFinancialsTool.net_profit`).

**判断阈值** (引用 `references/industry_benchmarks.json` — 必须用 `lookup_industry_benchmark`):

| 指标 | 健康 (DEFAULT) | 一般 | 警戒 | 高风险 |
|---|---|---|---|---|
| ROE | > 行业平均 1.5x (= 领先) | 行业平均 ± 30% | < 行业平均 50% | < 0 (亏损) |
| 毛利率 | > 30% (中性) | 15–30% | 5–15% | < 5% |
| 净利率 | > 10% | 5–10% | 0–5% | < 0 (亏损) |

**行业差异提醒** (关键):
- **白酒**: ROE 行业平均 0.20, 领先 0.30 (高毛利 + 强品牌); ROE < 15% 通常已是次梯队.
- **公用事业**: ROE 行业平均 0.08, 领先 0.13 (强监管 / 价格管制, 上限低); 看到 18% 反而要警惕.
- **科技互联网**: ROE 行业平均 0.15, 领先 0.30 (头部 / 长尾分化大, 关注是否有 SaaS 化变现).
- **医药生物**: ROE 行业平均 0.12, 领先 0.22 (创新药管线 vs 仿制药价差差异).
- **银行金融**: ROE 行业平均 0.10 (利差受监管约束).

**评估流程**:
1. 先查行业 ROE 基准 — `lookup_industry_benchmark(industry=..., indicator="ROE_行业平均")`.
2. 跟"行业平均的 1.5x"比较, > 这个倍数 = 领先.
3. 再看毛利率趋势, 跌穿 5pp = 定价权 / 成本端有恶化.
4. 最后看净利率, 跟毛利率背离 (毛利稳但净利跌) 通常意味费用率失控.

**写入 narrative 的标准句式**:
- "{target_name} ROE {X}% (行业平均 {Y}%), 处于{领先/中游/落后}水平."
- "毛利率近 {N} 期 {上升/稳定/下滑} {Z}pp, 反映{定价权/成本端}变化."
