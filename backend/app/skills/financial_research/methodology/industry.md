## § 2.2 行业景气 (Industry)

**关键指标** (来自 `web_search` Bocha):
- 行业政策周期: 鼓励 / 中性 / 压制 (查近 6 个月一行业政策文件 / 部委表态).
- 申万行业涨跌幅分位: 行业指数近 30 日 / 近 1 年涨跌幅相对全市场分位.
- 上下游景气: 上游原材料价格 + 下游需求趋势 (white-paper / 行业协会数据).
- 龙头公司表态: 头部 1–2 家公司业绩会 / 公告中的需求 / 价格 / 库存语言.

**判断阈值** (定性, 综合 web_search 输出 + 文本 sentiment):

| 维度 | 景气向上 | 中性 | 景气向下 |
|---|---|---|---|
| 政策方向 | 国家级鼓励 (双碳 / 信创 / 创新药 etc) | 维持现状 | 限价 / 反垄断 / 限购 |
| 涨跌幅分位 | > 70% (市场抢筹) | 30–70% | < 30% (持续杀跌) |
| 上游价格 | 平稳 / 成本压力小 | 小幅波动 | 大幅上涨 (压缩毛利) |
| 龙头表态 | "供不应求" / "提价" | "稳定" | "去库存" / "需求疲软" |

**行业差异提醒** (景气评估方法不同):
- **白酒**: 看终端动销 (中高端 vs 大众) + 春节 / 中秋开瓶率 — 量比价更敏感.
- **公用事业**: 看政策 (电价 / 水价改革) + 用电量 — 周期性极弱, 季度变化小.
- **科技互联网**: 看监管 (反垄断 / 数据安全) + AI / 云计算技术周期.
- **银行金融**: 看货币政策 + 不良率 + 净息差 (NIM) — 跟宏观货币高度相关.
- **房地产**: 看销售面积 yoy + 70 城房价 + 拿地强度 — 周期 + 政策双重支配.
- **医药生物**: 看医保谈判 / 集采轮次 + 创新药审批节奏 — 政策边际变化主导.

**评估流程**:
1. 先用 `web_search(query="{行业} 政策 近 6 个月")` 拿政策态度 (压制 / 中性 / 鼓励).
2. 再 `web_search(query="{行业} 申万指数 涨跌幅")` 拿市场表态.
3. 最后 `web_search(query="{龙头公司} 业绩会 需求 价格")` 拿龙头视角的微观信号.
4. 综合给行业景气定性: 强 / 中性 / 弱 — 用于 evidence 中标注 `industry_signal`, 喂给评级 DSL 的 fallback 判断.

**写入 narrative 的标准句式**:
- "{行业} 当前处于{景气向上/中性/景气向下}阶段, 主要驱动: [政策/需求/竞争格局描述]."
- "近 6 个月政策端 {鼓励/中性/压制}, 龙头公司 {提价/稳定/去库存}, 共同指向 {方向}."
