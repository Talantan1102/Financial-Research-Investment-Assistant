## 推荐新增 API 详细说明

### 1. 财务数据类（优先实现）

```python
# income - 利润表
# 返回字段：营业收入、营业成本、营业利润、净利润、EPS等
api.income(ts_code="600519.SH", start_date="20240101", end_date="20241231")

# balance_sheet - 资产负债表
# 返回字段：总资产、总负债、股东权益、流动资产等
api.balance_sheet(ts_code="600519.SH")

# cashflow - 现金流量表
# 返回字段：经营现金流、投资现金流、筹资现金流
api.cashflow(ts_code="600519.SH")

# fina_indicator - 财务指标（一站式）
# 返回字段：ROE、ROA、毛利率、净利率、资产负债率等
api.fina_indicator(ts_code="600519.SH")
```

### 2. 每日指标类（优先实现）

```python
# daily_basic - 每日指标
# 返回字段：收盘价、换手率、市盈率、市净率、总市值、流通市值
api.daily_basic(ts_code="600519.SH", trade_date="20250314")
```

### 3. 资金流向类（优先实现）

```python
# moneyflow_hsgt - 沪深港通资金流向
# 返回字段：北向资金净流入、南向资金净流入
api.moneyflow_hsgt(start_date="20250301", end_date="20250314")
```
