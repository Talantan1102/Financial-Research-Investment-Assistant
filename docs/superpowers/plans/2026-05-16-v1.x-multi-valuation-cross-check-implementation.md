# v1.x A5a — 多模型估值 cross-check Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实施 v1.x A5a 多模型估值 cross-check — 4 个 Python valuation helper(PE / PB / EV-EBITDA / DCF)+ 行业 router(deterministic + LLM override)+ OutlierDiagnosisAgent + Critic 第 7 维 + Writer 引用约束。让 `InvestmentDueDiligenceReport.ValuationAnalysis` 从单 lens(PE 历史分位)升级到多 lens cross-check + 显式诊断。

**Architecture:** Python deterministic 算 4 模型数字(沿用 v0.8.5 / v1.x A4 主线),DCF 走 3 场景 base/bull/bear + sensitivity 矩阵。IndustryModelRouter 用 deterministic mapping 覆盖 80% 行业,LLM judgment override 处理边界 case(腾讯/美团跨界)。Cross-check severe divergence 时触发 OutlierDiagnosisAgent LLM 诊断,Writer narrative 必须引用,Critic 新维守护。

**Tech Stack:** Python 3.11+ / Pydantic v2 / LangGraph 1.1 / tushare client(已 ship) / pytest-asyncio / VCR cassette / pytest-vcr。沿用 backend/app/agents/ 现有 Agent ABC 范式。

"""v1.x A5a: Valuation helper exceptions."""

from __future__ import annotations


class InsufficientDataForModel(Exception):
    """raised when a Python valuation helper cannot compute due to missing/invalid input.

    Caller (ValuationCalculator) catches this and removes the failing model from
    `active_models`, then continues with the remaining models. Narrative will reflect
    which models were skipped and why (Writer prompt has explicit instruction).
    """

    def __init__(self, *, model: str, missing_field: str, reason: str) -> None:
        self.model = model
        self.missing_field = missing_field
        self.reason = reason
        super().__init__(f"model={model} missing_field={missing_field}: {reason}")
```

"""v1.x A5a: PE 估值 helper.

PE = price / eps. implied_price = eps × industry_pe_target.

industry_pe_target = (industry_pe_avg + industry_pe_median) / 2,弱化极端可比公司影响。
spec ref: 2026-05-16-v1.x-multi-valuation-cross-check-design.md § 4
"""

from __future__ import annotations

from app.agents.valuation_helpers.exceptions import InsufficientDataForModel

__all__ = ["compute_pe_value"]


def compute_pe_value(
    *,
    eps: float,
    industry_pe_avg: float,
    industry_pe_median: float,
) -> float:
    """计算 PE 理论价。

    Raises:
        InsufficientDataForModel: eps ≤ 0(亏损/无盈利)or 行业 PE 缺失
    """
    if eps <= 0:
        raise InsufficientDataForModel(
            model="pe",
            missing_field="eps",
            reason=f"eps={eps} ≤ 0 (亏损或零利润, PE 失效)",
        )
    if industry_pe_avg <= 0 and industry_pe_median <= 0:
        raise InsufficientDataForModel(
            model="pe",
            missing_field="industry_pe",
            reason="industry_pe_avg + industry_pe_median 均 ≤ 0",
        )

    valid_pes = [p for p in (industry_pe_avg, industry_pe_median) if p > 0]
    industry_pe_target = sum(valid_pes) / len(valid_pes)
    return eps * industry_pe_target
```

"""v1.x A5a: EV/EBITDA 估值 helper.

EV/EBITDA = (market_cap + net_debt) / EBITDA. implied_price calculation:
1. target_ev = ebitda × industry_ev_ebitda_target
2. implied_market_cap = target_ev - net_debt
3. implied_price = implied_market_cap / shares_outstanding

适用跨负债结构对比(并购 / 重资本)。对零负债公司,信号跟 PE 高度相关。
spec ref: 2026-05-16-v1.x-multi-valuation-cross-check-design.md § 4
"""

from __future__ import annotations

from app.agents.valuation_helpers.exceptions import InsufficientDataForModel

__all__ = ["compute_ev_ebitda_value"]


def compute_ev_ebitda_value(
    *,
    ebitda: float,
    net_debt: float,
    shares_outstanding: float,
    industry_ev_ebitda_avg: float,
    industry_ev_ebitda_median: float,
) -> float:
    if ebitda <= 0:
        raise InsufficientDataForModel(
            model="ev_ebitda",
            missing_field="ebitda",
            reason=f"ebitda={ebitda} ≤ 0 (负 EBITDA, 模型失效)",
        )
    if shares_outstanding <= 0:
        raise InsufficientDataForModel(
            model="ev_ebitda",
            missing_field="shares_outstanding",
            reason=f"shares_outstanding={shares_outstanding} ≤ 0",
        )
    if industry_ev_ebitda_avg <= 0 and industry_ev_ebitda_median <= 0:
        raise InsufficientDataForModel(
            model="ev_ebitda",
            missing_field="industry_ev_ebitda",
            reason="industry_ev_ebitda_avg + median 均 ≤ 0",
        )

    valid_multiples = [m for m in (industry_ev_ebitda_avg, industry_ev_ebitda_median) if m > 0]
    industry_target = sum(valid_multiples) / len(valid_multiples)

    target_ev = ebitda * industry_target
    implied_market_cap = target_ev - net_debt
    implied_price = implied_market_cap / shares_outstanding

    # Clamp at 0 if debt > target_ev (边界 case,narrative 应 flag)
    return max(implied_price, 0.0)
```

"""v1.x A5a: DCF 估值 helper.

3 sub-functions:
1. compute_growth_trajectory  — 10 年增速序列(3 场景:base/bull/bear)
2. compute_company_wacc       — 简化 CAPM + β/leverage 调整
3. compute_dcf_value          — 主入口,产 base/bull/bear 三个理论价
4. compute_dcf_sensitivity    — 5×5 矩阵(WACC × Terminal Growth)

Design 范式:**数字 Python deterministic / judgment LLM**。所有数字 deterministic;
LLM 仅在 `base` 场景的启动增长率可 override(模拟"研究员调增长率"高频动作)。
WACC / terminal growth 不让 LLM 改(金融学公式锚定 + 团队 view 范式)。

spec ref: 2026-05-16-v1.x-multi-valuation-cross-check-design.md § 6
"""

from __future__ import annotations

from typing import Literal

from app.agents.valuation_helpers.exceptions import InsufficientDataForModel

__all__ = [
    "compute_growth_trajectory",
    # compute_company_wacc — added in Task 7
    # compute_dcf_value — added in Task 7
    # compute_dcf_sensitivity — added in Task 8
]


def compute_growth_trajectory(
    *,
    historical_growth: list[float],
    forecast_growth: float | None,
    industry_terminal: float,
    scenario: Literal["base", "bull", "bear"],
    n_years: int = 10,
) -> list[float]:
    """生成 n 年增速序列,从启动值线性 decay 到 industry_terminal。

    启动值:
      - base: forecast if available else avg(historical)  (管理层 > 历史外推)
      - bull: max(historical_avg, forecast) × 1.2
      - bear: min(historical_avg, forecast) × 0.8

    若启动值 < terminal,全序列 clamp 至 terminal。
    """
    if not historical_growth and forecast_growth is None:
        raise InsufficientDataForModel(
            model="dcf",
            missing_field="growth_signal",
            reason="historical_growth 空 + forecast_growth=None,无法估计增长率",
        )

    historical_avg = (
        sum(historical_growth) / len(historical_growth) if historical_growth else None
    )

    if scenario == "base":
        start = forecast_growth if forecast_growth is not None else historical_avg
    elif scenario == "bull":
        signals = [g for g in (historical_avg, forecast_growth) if g is not None]
        start = max(signals) * 1.2
    elif scenario == "bear":
        signals = [g for g in (historical_avg, forecast_growth) if g is not None]
        start = min(signals) * 0.8
    else:
        raise ValueError(f"invalid scenario: {scenario}")

    assert start is not None  # narrowed by branches above

    # Linear decay from start → terminal across n_years
    if start <= industry_terminal:
        return [industry_terminal] * n_years

    step = (start - industry_terminal) / (n_years - 1) if n_years > 1 else 0.0
    return [max(start - step * i, industry_terminal) for i in range(n_years)]
```

def compute_company_wacc(
    *,
    industry_baseline_wacc: float,
    company_beta: float | None,
    debt_to_equity: float,
) -> float:
    """简化 CAPM 调整:WACC = industry_baseline + β_adj + leverage_adj。

    - β_adj = (β - 1.0) × 0.02 (β 偏离 1.0 → 风险 ±2%)
    - leverage_adj = 0.01 if d/e > 1.0 else 0 (高杠杆风险溢价)
    - 缺 β 时 β_adj = 0(行业 baseline fallback)
    """
    beta_adj = (company_beta - 1.0) * 0.02 if company_beta is not None else 0.0
    leverage_adj = 0.01 if debt_to_equity > 1.0 else 0.0
    return industry_baseline_wacc + beta_adj + leverage_adj


def compute_dcf_value(
    *,
    free_cash_flow_base: float,
    shares_outstanding: float,
    growth_trajectory: list[float],
    terminal_growth: float,
    wacc: float,
) -> float:
    """单场景 DCF 主入口。"""
    if shares_outstanding <= 0:
        raise InsufficientDataForModel(
            model="dcf",
            missing_field="shares_outstanding",
            reason=f"shares_outstanding={shares_outstanding} ≤ 0",
        )
    if free_cash_flow_base <= 0:
        raise InsufficientDataForModel(
            model="dcf",
            missing_field="free_cash_flow_base",
            reason=f"FCF base={free_cash_flow_base} ≤ 0 (DCF 不适用亏损公司)",
        )
    if terminal_growth >= wacc:
        raise InsufficientDataForModel(
            model="dcf",
            missing_field="terminal_growth_vs_wacc",
            reason=f"terminal_growth={terminal_growth} ≥ wacc={wacc} (Gordon Growth 发散)",
        )

    n = len(growth_trajectory)
    # 1. 算每年 FCF
    fcf_t: list[float] = []
    fcf_prev = free_cash_flow_base
    for g in growth_trajectory:
        fcf_t.append(fcf_prev * (1.0 + g))
        fcf_prev = fcf_t[-1]

    # 2. 折现各年 FCF
    pv_fcf_total = 0.0
    for t, fcf in enumerate(fcf_t, start=1):
        pv_fcf_total += fcf / ((1.0 + wacc) ** t)

    # 3. Terminal value (Gordon Growth)
    fcf_n_plus_1 = fcf_t[-1] * (1.0 + terminal_growth)
    terminal_value = fcf_n_plus_1 / (wacc - terminal_growth)
    pv_terminal = terminal_value / ((1.0 + wacc) ** n)

    # 4. Enterprise value → implied price
    enterprise_value = pv_fcf_total + pv_terminal
    return enterprise_value / shares_outstanding
```

def compute_dcf_sensitivity(
    *,
    free_cash_flow_base: float,
    shares_outstanding: float,
    growth_trajectory: list[float],
    base_terminal_growth: float,
    base_wacc: float,
    wacc_deltas: tuple[float, ...] = (-0.02, -0.01, 0.0, 0.01, 0.02),
    terminal_deltas: tuple[float, ...] = (-0.01, -0.005, 0.0, 0.005, 0.01),
) -> list[list[float]]:
    """生成 5×5 sensitivity matrix。"""
    matrix: list[list[float]] = []
    for wacc_d in wacc_deltas:
        row: list[float] = []
        wacc = base_wacc + wacc_d
        for terminal_d in terminal_deltas:
            terminal = base_terminal_growth + terminal_d
            try:
                v = compute_dcf_value(
                    free_cash_flow_base=free_cash_flow_base,
                    shares_outstanding=shares_outstanding,
                    growth_trajectory=growth_trajectory,
                    terminal_growth=terminal,
                    wacc=wacc,
                )
                row.append(v)
            except InsufficientDataForModel:
                row.append(0.0)  # 发散 cell fallback
        matrix.append(row)
    return matrix

"""v1.x A5a: cross-check consistency analyzer.

Coefficient of variation (CV) = std / mean.
  CV < 15%   → consistent (lens 信号一致, narrative 可简明)
  15-30%     → moderate   (narrative 需解释偏离原因)
  > 30%      → severe     (触发 OutlierDiagnosisAgent + Writer 必须显式引用)

零值(clamp 后的 EV/EBITDA)忽略,不算入 CV。
spec ref: 2026-05-16-v1.x-multi-valuation-cross-check-design.md § 7
"""

from __future__ import annotations

import math
from typing import Literal

__all__ = ["analyze_consistency"]

ConsistencyLevel = Literal["consistent", "moderate", "severe"]


def analyze_consistency(valuations: dict[str, float]) -> ConsistencyLevel | None:
    """单 lens 或空 → None;多 lens → severity by CV."""
    valid = [v for v in valuations.values() if v > 0]
    if len(valid) < 2:
        return None

    mean = sum(valid) / len(valid)
    if mean == 0:
        return None

    variance = sum((v - mean) ** 2 for v in valid) / len(valid)
    std = math.sqrt(variance)
    cv = std / mean

    if cv < 0.15:
        return "consistent"
    if cv < 0.30:
        return "moderate"
    return "severe"
```

    "煤炭": [ValuationModel.EV_EBITDA, ValuationModel.PB],
    "化工": [ValuationModel.EV_EBITDA, ValuationModel.PB],
    # 重资本 / 公用
    "电信运营": [ValuationModel.EV_EBITDA, ValuationModel.DCF],
    "电力": [ValuationModel.PB, ValuationModel.EV_EBITDA],
    "公用事业": [ValuationModel.PB],
    # Fallback
    "_default": [ValuationModel.PE, ValuationModel.DCF],

class RouterOverride(BaseModel):
    """LLM analyst 在 deterministic mapping 之上的 judgment override 输出。

    Analyst 看公司 narrative,如果发现"跨界 / 业务模式特殊",可 override 默认 models。
    必须给 reasoning(审计 trail) + confidence(高 = 强信号,低 = 拍脑袋)。
    """

    model_config = ConfigDict(frozen=True)

    override_models: list[ValuationModel] = Field(min_length=1, max_length=4)
    reasoning: str = Field(max_length=200)
    confidence: Literal["high", "medium", "low"]


def lookup_default_models(industry_classification: str) -> list[ValuationModel]:
    """查表;未命中 → _default fallback。"""
    return INDUSTRY_VALUATION_MAPPING.get(
        industry_classification, INDUSTRY_VALUATION_MAPPING["_default"]
    )


def apply_llm_override(
    default_models: list[ValuationModel],
    override: RouterOverride | None,
) -> tuple[list[ValuationModel], str | None]:
    """if override is not None → 使用 override.override_models + reasoning。
    else → 保留 default,reasoning=None。
    """
    if override is None:
        return default_models, None
    return list(override.override_models), override.reasoning

"""v1.x A5a: ValuationCalculator orchestrator.

flow:
1. IndustryModelRouter → active_models
2. 对每个 active model 调对应 Python helper:
   - PE → compute_pe_value
   - PB → compute_pb_value
   - EV_EBITDA → compute_ev_ebitda_value
   - DCF → growth_trajectory × 3 (base/bull/bear) + compute_dcf_value × 3 + sensitivity
3. helper 失败(InsufficientDataForModel)→ skip,记 skipped_models[model] = reason
4. analyze_consistency on collected non-None values (DCF 只用 dcf_base)

输出 ValuationResult dataclass。caller(Analyst node)拷贝到 ValuationAnalysis schema。

spec ref: 2026-05-16-v1.x-multi-valuation-cross-check-design.md § 8
"""

from __future__ import annotations

from dataclasses import dataclass, field
from typing import Literal

from app.agents.industry_model_router import (
    RouterOverride,
    apply_llm_override,
    lookup_default_models,
)
from app.agents.investment_dd_schema import ValuationModel
from app.agents.valuation_helpers.consistency import analyze_consistency
from app.agents.valuation_helpers.dcf import (
    compute_company_wacc,
    compute_dcf_sensitivity,
    compute_dcf_value,
    compute_growth_trajectory,
)
from app.agents.valuation_helpers.ev_ebitda import compute_ev_ebitda_value
from app.agents.valuation_helpers.exceptions import InsufficientDataForModel
from app.agents.valuation_helpers.pb import compute_pb_value
from app.agents.valuation_helpers.pe import compute_pe_value

__all__ = ["ValuationInputs", "ValuationResult", "calculate_valuations"]


@dataclass
class ValuationInputs:
    industry_classification: str
    industry_pe_avg: float
    industry_pe_median: float
    industry_pb_avg: float
    industry_pb_median: float
    industry_ev_ebitda_avg: float
    industry_ev_ebitda_median: float
    industry_baseline_wacc: float
    industry_terminal_growth: float

    eps: float
    book_value_per_share: float
    ebitda: float
    net_debt: float
    shares_outstanding: float
    free_cash_flow_base: float
    historical_growth: list[float]
    forecast_growth: float | None
    company_beta: float | None
    debt_to_equity: float


@dataclass
class ValuationResult:
    active_models: list[ValuationModel]
    router_override_reasoning: str | None = None
    pe_value: float | None = None
    pb_value: float | None = None
    ev_ebitda_value: float | None = None
    dcf_base: float | None = None
    dcf_bull: float | None = None
    dcf_bear: float | None = None
    dcf_sensitivity: list[list[float]] | None = None
    valuation_consistency: Literal["consistent", "moderate", "severe"] | None = None
    skipped_models: dict[ValuationModel, str] = field(default_factory=dict)


def calculate_valuations(
    inputs: ValuationInputs,
    router_override: RouterOverride | None,
) -> ValuationResult:
    default_models = lookup_default_models(inputs.industry_classification)
    active_models, override_reasoning = apply_llm_override(default_models, router_override)

    result = ValuationResult(
        active_models=list(active_models),
        router_override_reasoning=override_reasoning,
    )

    for model in active_models:
        try:
            if model == ValuationModel.PE:
                result.pe_value = compute_pe_value(
                    eps=inputs.eps,
                    industry_pe_avg=inputs.industry_pe_avg,
                    industry_pe_median=inputs.industry_pe_median,
                )
            elif model == ValuationModel.PB:
                result.pb_value = compute_pb_value(
                    book_value_per_share=inputs.book_value_per_share,
                    industry_pb_avg=inputs.industry_pb_avg,
                    industry_pb_median=inputs.industry_pb_median,
                )
            elif model == ValuationModel.EV_EBITDA:
                result.ev_ebitda_value = compute_ev_ebitda_value(
                    ebitda=inputs.ebitda,
                    net_debt=inputs.net_debt,
                    shares_outstanding=inputs.shares_outstanding,
                    industry_ev_ebitda_avg=inputs.industry_ev_ebitda_avg,
                    industry_ev_ebitda_median=inputs.industry_ev_ebitda_median,
                )
            elif model == ValuationModel.DCF:
                wacc = compute_company_wacc(
                    industry_baseline_wacc=inputs.industry_baseline_wacc,
                    company_beta=inputs.company_beta,
                    debt_to_equity=inputs.debt_to_equity,
                )
                # 3 场景
                for scenario_name in ("base", "bull", "bear"):
                    trajectory = compute_growth_trajectory(
                        historical_growth=inputs.historical_growth,
                        forecast_growth=inputs.forecast_growth,
                        industry_terminal=inputs.industry_terminal_growth,
                        scenario=scenario_name,  # type: ignore[arg-type]
                    )
                    price = compute_dcf_value(
                        free_cash_flow_base=inputs.free_cash_flow_base,
                        shares_outstanding=inputs.shares_outstanding,
                        growth_trajectory=trajectory,
                        terminal_growth=inputs.industry_terminal_growth,
                        wacc=wacc,
                    )
                    if scenario_name == "base":
                        result.dcf_base = price
                    elif scenario_name == "bull":
                        result.dcf_bull = price
                    elif scenario_name == "bear":
                        result.dcf_bear = price

                # sensitivity (基于 base 场景的 trajectory)
                base_trajectory = compute_growth_trajectory(
                    historical_growth=inputs.historical_growth,
                    forecast_growth=inputs.forecast_growth,
                    industry_terminal=inputs.industry_terminal_growth,
                    scenario="base",
                )
                result.dcf_sensitivity = compute_dcf_sensitivity(
                    free_cash_flow_base=inputs.free_cash_flow_base,
                    shares_outstanding=inputs.shares_outstanding,
                    growth_trajectory=base_trajectory,
                    base_terminal_growth=inputs.industry_terminal_growth,
                    base_wacc=wacc,
                )
        except InsufficientDataForModel as e:
            result.skipped_models[model] = e.reason

    # consistency: 收集成功的 lens (DCF 用 base 场景)
    valid: dict[str, float] = {}
    if result.pe_value is not None:
        valid["pe"] = result.pe_value
    if result.pb_value is not None:
        valid["pb"] = result.pb_value
    if result.ev_ebitda_value is not None:
        valid["ev_ebitda"] = result.ev_ebitda_value
    if result.dcf_base is not None:
        valid["dcf_base"] = result.dcf_base

    result.valuation_consistency = analyze_consistency(valid)
    return result
```

from app.services.llm_service import LLMService

__all__ = ["OutlierDiagnosisAgent"]

logger = logging.getLogger(__name__)


_PROMPT_TEMPLATE = """你是资深尽调研究员,专门诊断多模型估值不一致(cross-check divergence)的成因。

公司:{company_narrative}

各 lens 计算结果:
{valuations_block}

各模型关键假设:
{assumptions_block}

你的任务:
1. 找出最偏离 consensus 的 lens(outlier_model)
2. 诊断 outlier 的关键假设错在哪(likely_cause, ≤300 字符)
3. 评估你的诊断有多大把握(confidence: high/medium/low)
4. 推荐处理动作(recommended_action):
   - trust_consensus: 信另外几个 lens,outlier 应忽略
   - flag_uncertainty: 报告里 flag 给用户决定
   - recompute_assumption: 调整假设重算(本期不实施)
5. 写给客户的 narrative(≤500 字符):用大白话讲清打架原因 + 建议

输出 OutlierDiagnosis JSON。"""


class OutlierDiagnosisAgent:
    """LLM-based outlier diagnostician."""

    def __init__(self, *, llm: LLMService) -> None:
        self._llm = llm

    async def diagnose(
        self,
        valuations: dict[str, float],
        assumptions: dict[str, dict],
        company_narrative: str,
    ) -> OutlierDiagnosis | None:
        """输出 OutlierDiagnosis 或 None (LLM 失败时)."""
        prompt = _PROMPT_TEMPLATE.format(
            company_narrative=company_narrative,
            valuations_block=json.dumps(valuations, ensure_ascii=False, indent=2),
            assumptions_block=json.dumps(assumptions, ensure_ascii=False, indent=2),
        )

        try:
            response = await self._llm.chat(
                prompt=prompt,
                schema=OutlierDiagnosis,
                tier="balanced",
            )
            content = response.content
            if isinstance(content, OutlierDiagnosis):
                return content
            # 若 LLMService 返回 raw JSON string,parse it
            if isinstance(content, str):
                return OutlierDiagnosis.model_validate_json(content)
            if isinstance(content, dict):
                return OutlierDiagnosis.model_validate(content)
            logger.warning("OutlierDiagnosis unexpected content type: %s", type(content))
            return None
        except Exception as e:
            logger.warning("OutlierDiagnosisAgent failed: %s", e)
            return None
```

```python
"""v1.x A5a: Critic 第 7 维 — valuation_consistency scorer.

Rule-based 评分(不调 LLM,deterministic):
  - consistency=None      → 10.0 (skip, 单 lens 无 cross-check)
  - consistency=consistent + narrative 提一致性 → 9.0
  - consistency=consistent + narrative 未提 → 8.0
  - consistency=moderate + narrative 含'偏离/差异/偏低/偏高' → 8.0
  - consistency=moderate + narrative 未提偏离 → 4.0
  - consistency=severe + narrative 引用 diagnosis.narrative substring → 9.0
  - consistency=severe + narrative 未引用 → 3.0

阈值 < 7.0 触发 writer retry (沿用 retry edge,见 § 9.2 spec)。

spec ref: 2026-05-16-v1.x-multi-valuation-cross-check-design.md § 9.2
"""

from __future__ import annotations

from typing import Literal

from app.agents.investment_dd_schema import OutlierDiagnosis
from app.agents.schemas import CriticDimensionScore
from app.services.llm_service import LLMService

__all__ = ["ValuationConsistencyScorer"]


_MODERATE_KEYWORDS = ("偏离", "差异", "偏低", "偏高", "存在", "不一致")
_CONSISTENT_KEYWORDS = ("一致", "吻合", "趋同", "接近")


class ValuationConsistencyScorer:
    """Critic 第 7 维 scorer. Rule-based, deterministic."""

    dimension = "valuation_consistency"

    def __init__(self, *, llm: LLMService) -> None:
        # LLM 当前不用(rule-based),但保留 DI 接口以备 future
        self._llm = llm

    async def score(
        self,
        *,
        report_markdown: str,
        valuation_consistency: Literal["consistent", "moderate", "severe"] | None,
        outlier_diagnosis: OutlierDiagnosis | None,
        request_id: str = "rule-based-no-llm-call",
    ) -> CriticDimensionScore:
        if valuation_consistency is None:
            return CriticDimensionScore(
                dimension=self.dimension,  # type: ignore[arg-type]
                score=10.0,
                evidence="single-lens skip (no cross-check applicable)",
                sub_agent_request_id=request_id,
            )

        if valuation_consistency == "consistent":
            mentions = any(kw in report_markdown for kw in _CONSISTENT_KEYWORDS)
            score = 9.0 if mentions else 8.0
            evidence = (
                "consistent + narrative 提及一致性" if mentions else "consistent (narrative 未显式提一致性)"
            )
            return CriticDimensionScore(
                dimension=self.dimension,  # type: ignore[arg-type]
                score=score,
                evidence=evidence,
                sub_agent_request_id=request_id,
            )

        if valuation_consistency == "moderate":
            mentions = any(kw in report_markdown for kw in _MODERATE_KEYWORDS)
            score = 8.0 if mentions else 4.0
            evidence = (
                "moderate + narrative 解释偏离" if mentions else "moderate (narrative 未提偏离原因)"
            )
            return CriticDimensionScore(
                dimension=self.dimension,  # type: ignore[arg-type]
                score=score,
                evidence=evidence,
                sub_agent_request_id=request_id,
            )

        # severe
        if outlier_diagnosis is None:
            # severe 但 diagnosis 未产出(LLM 失败 fallback)— narrative 至少应 flag 不确定性
            mentions_flag = "无法诊断" in report_markdown or "不确定" in report_markdown
            score = 7.0 if mentions_flag else 4.0
            evidence = (
                "severe + diagnosis 缺失,narrative flag 不确定"
                if mentions_flag
                else "severe + diagnosis 缺失,narrative 也未 flag"
            )
            return CriticDimensionScore(
                dimension=self.dimension,  # type: ignore[arg-type]
                score=score,
                evidence=evidence,
                sub_agent_request_id=request_id,
            )

        # severe + diagnosis exists → narrative 必须引用 diagnosis.narrative substring
        diagnosis_referenced = outlier_diagnosis.narrative in report_markdown
        score = 9.0 if diagnosis_referenced else 3.0
        evidence = (
            "severe + narrative 显式引用 diagnosis"
            if diagnosis_referenced
            else "severe + narrative 未引用 diagnosis (掩盖打架信号)"
        )
        return CriticDimensionScore(
            dimension=self.dimension,  # type: ignore[arg-type]
            score=score,
            evidence=evidence,
            sub_agent_request_id=request_id,
        )
```
