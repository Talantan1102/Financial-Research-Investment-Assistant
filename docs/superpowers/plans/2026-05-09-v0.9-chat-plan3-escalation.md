# v0.9 Chat — Plan 3: Escalation Channel (LLM-fill EscalationPacket + User Confirm + Report Integration)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the chat→research escalation channel — the "坑 3" deliverable. When the chat planner emits `escalate_offered=True`, a backend LLM looks at the full chat history once and fills an `EscalationPacket` draft with 4 signal classes (ExplicitTask / ChatDerivedSignals / KnownFacts / SessionMetadata + MissingFieldHint list). The packet draft is streamed to the frontend via SSE; the user confirms / inline-edits it (UI lands in Plan 4, this plan provides the wire format and `/api/v0/chat/escalate` endpoint). Backend persists the LLM draft + user-confirmed packet + diff (`user_edits`) in `EscalationRecord` PG table for prompt-tuning trace, then converts the confirmed packet into `ResearchState` (with 4 NEW chat-derived fields), invokes the existing v0.8.5 ResearchAgent pipeline, and double-writes the report into both the `research_reports` table and a `ChatMessage(message_type="research_report", research_report_id, research_report_summary)` row.

**Architecture:** A new `EscalationExtractor` agent (constrained-LLM, similar shape to `ChatPlanner`) produces packet drafts. A new `EscalationProtocol` Pydantic schema (this is the *wire format*) is shared between SSE event payloads, the `/api/v0/chat/escalate` request body, and the `EscalationRecord` jsonb columns. The existing chat router gains two new SSE event types (`escalate_request` / `escalate_packet_draft`) emitted between `done` and the user's confirm. A new endpoint `POST /api/v0/chat/escalate` accepts the confirmed packet, writes `EscalationRecord(packet_draft, packet_confirmed, user_edits)`, builds an extended `ResearchState`, invokes the research subgraph (already migrated to AsyncPostgresSaver in Plan 1), streams `research_*` events back, and on completion writes both `research_reports.source_chat_session_id` and the `ChatMessage(message_type="research_report")` linkage.

**Tech Stack:** Python 3.11+ / FastAPI / Pydantic v2 / DashScope LLM via `LLMService` / SQLAlchemy + PG 15 / pytest + monkeypatch + pg_test_container_pattern / LangGraph 1.x ResearchAgent (untouched pipeline; prompt-only honor of new chat-derived fields).

```python
"""EscalationPacket — wire format for chat→research escalation handoff.

Per spec § 4.4.  This module is the single source of truth for the protocol;
it is shared between:

  - SSE event ``escalate_packet_draft`` payload (backend → frontend)
  - ``POST /api/v0/chat/escalate`` request body (frontend → backend)
  - ``EscalationRecord`` jsonb columns (PG persistence)
  - ``ResearchState.chat_extracted_*`` fields (research subgraph input)

Industrial problem E1 ("packet schema 4 类 signal") is fully landed here.
The 4 main classes are: ExplicitTask / ChatDerivedSignals / KnownFacts /
SessionMetadata.  ``MissingFieldHint`` is the LLM-detected uncertainty signal
that the frontend confirm dialog renders as "⚠️ 需补充" inline questions.
"""

from __future__ import annotations

from datetime import datetime
from typing import Any, Literal

from pydantic import BaseModel, ConfigDict, Field


class ExplicitTask(BaseModel):
    """The user's explicit deep-research request, extracted from the last user turn."""

    raw_last_user_turn: str
    extracted_intent: str  # e.g. "full_due_diligence", "comparative_analysis"
    target_ts_code: str | None = None
    target_entity_name: str | None = None
    user_extra_message: str | None = None  # any extra context user typed on confirm


class Entity(BaseModel):
    """A target / comparative / passing entity mentioned in the chat."""

    name: str
    ts_code: str | None = None
    role: Literal["primary_target", "comparative_target", "mentioned_in_passing"]
    mention_turn_indices: list[int] = Field(default_factory=list)


class Preference(BaseModel):
    """User preference / disposition extracted from chat history."""

    text: str
    category: Literal[
        "risk_tolerance", "focus_metric", "comparative_focus", "horizon", "other",
    ]
    confidence: float = Field(ge=0.0, le=1.0)


class ChatDerivedSignals(BaseModel):
    """Signals the LLM extracted from the full chat history (deferred from in-session per § 2.2)."""

    entities: list[Entity] = Field(default_factory=list)
    preferences: list[Preference] = Field(default_factory=list)
    open_questions: list[str] = Field(default_factory=list)
    inferred_persona: str | None = None
    extraction_confidence: float = Field(ge=0.0, le=1.0, default=0.0)


class ToolResultRef(BaseModel):
    """Reference to a cached tool result (so research subgraph can skip duplicate work)."""

    tool_name: str
    tool_args: dict[str, Any] = Field(default_factory=dict)
    result_summary: str  # 1-line natural-language summary, NOT the raw payload
    cached_at: datetime
    cache_id: str  # PK in ToolResultCache (user_id::tool::hash)


class KnownFacts(BaseModel):
    """Facts already established during chat — research planner can skip these tools."""

    tool_results: list[ToolResultRef] = Field(default_factory=list)


class FieldEdit(BaseModel):
    """One inline edit user made in the confirm dialog (E12 packet diff trace)."""

    model_config = ConfigDict(arbitrary_types_allowed=True)

    field_path: str  # e.g. "chat_derived_signals.preferences[0].text"
    llm_value: Any
    user_value: Any
    edit_type: Literal["modify", "delete", "add"]


class SessionMetadata(BaseModel):
    """Chat session context + user-edit trace."""

    chat_session_id: str
    chat_turn_count: int
    chat_history_summary: str | None = None
    user_confirmed_at: datetime
    user_edits: list[FieldEdit] = Field(default_factory=list)


class MissingFieldHint(BaseModel):
    """LLM-detected missing or uncertain field (E10 missing-field detect)."""

    field_path: str
    reason: Literal["llm_uncertain", "schema_required_but_empty", "user_skipped"]
    llm_question_for_user: str  # rendered as inline question in confirm dialog


class EscalationPacket(BaseModel):
    """Full escalation packet — 4 signal classes + missing-field hints."""

    explicit_task: ExplicitTask
    chat_derived_signals: ChatDerivedSignals
    known_facts: KnownFacts
    session_metadata: SessionMetadata
    missing_field_hints: list[MissingFieldHint] = Field(default_factory=list)
```

"""EscalationRecord ORM — chat→research escalation persistence (E12 trace).

Per spec § 4.4 + § 4.6.  Three jsonb columns capture the LLM extraction +
user confirmation diff for prompt-tuning signal:

  - packet_draft:     LLM's first-pass EscalationPacket (verbatim)
  - packet_confirmed: user-confirmed final packet sent into ResearchAgent
  - user_edits:       list[FieldEdit] — diff between draft and confirmed

Status state machine:
  draft -> confirmed -> running -> completed (or failed)
"""

from __future__ import annotations

from datetime import datetime

from sqlalchemy import JSON, Column, DateTime, ForeignKey, String, func
from sqlalchemy.dialects.postgresql import JSONB

from app.core.database import Base


class EscalationRecord(Base):
    __tablename__ = "escalation_records"

    id = Column(String(64), primary_key=True)  # esc-<16hex>
    session_id = Column(
        String(64),
        ForeignKey("chat_sessions.id", ondelete="CASCADE"),
        nullable=False,
        index=True,
    )

    # 3 jsonb cols — sqlite fallback to JSON for L0 unit tests
    packet_draft = Column(JSONB().with_variant(JSON, "sqlite"), nullable=False)
    packet_confirmed = Column(JSONB().with_variant(JSON, "sqlite"), nullable=True)
    user_edits = Column(JSONB().with_variant(JSON, "sqlite"), nullable=True)

    research_report_id = Column(
        String(64),
        ForeignKey("research_reports.id", ondelete="SET NULL"),
        nullable=True,
        index=True,
    )

    # status: draft|confirmed|running|completed|failed
    status = Column(String(16), nullable=False, default="draft", index=True)

    created_at = Column(DateTime(timezone=True), server_default=func.now(), nullable=False)
    confirmed_at = Column(DateTime(timezone=True), nullable=True)
    completed_at = Column(DateTime(timezone=True), nullable=True)
    error_msg = Column(String(2048), nullable=True)
```

"""EscalationRecordRepo — CRUD for the chat→research handoff trace table."""

from __future__ import annotations

from datetime import datetime, timezone
from typing import Any, Callable
from uuid import uuid4

from sqlalchemy import select, update
from sqlalchemy.ext.asyncio import AsyncSession

from app.models.escalation_record import EscalationRecord


class EscalationRecordRepo:
    def __init__(self, session_factory: Callable[[], AsyncSession]) -> None:
        self._sf = session_factory

    async def create_draft(
        self,
        *,
        session_id: str,
        packet_draft: dict[str, Any],
    ) -> EscalationRecord:
        """Persist the LLM-fill draft and return the record (status=draft)."""
        async with self._sf() as sess:
            rid = f"esc-{uuid4().hex[:16]}"
            row = EscalationRecord(
                id=rid, session_id=session_id,
                packet_draft=packet_draft, status="draft",
            )
            sess.add(row)
            await sess.commit()
            await sess.refresh(row)
            return row

    async def get(self, record_id: str) -> EscalationRecord | None:
        async with self._sf() as sess:
            return await sess.get(EscalationRecord, record_id)

    async def record_confirmation(
        self,
        *,
        record_id: str,
        packet_confirmed: dict[str, Any],
        user_edits: list[dict[str, Any]],
    ) -> None:
        """Atomically write confirmed packet + user_edits diff (E12 trace)."""
        async with self._sf() as sess:
            await sess.execute(
                update(EscalationRecord).where(EscalationRecord.id == record_id).values(
                    packet_confirmed=packet_confirmed,
                    user_edits=user_edits,
                    status="confirmed",
                    confirmed_at=datetime.now(timezone.utc),
                )
            )
            await sess.commit()

    async def attach_research_report(
        self, record_id: str, *, research_report_id: str
    ) -> None:
        async with self._sf() as sess:
            await sess.execute(
                update(EscalationRecord).where(EscalationRecord.id == record_id).values(
                    research_report_id=research_report_id,
                )
            )
            await sess.commit()

    async def update_status(
        self,
        record_id: str,
        *,
        status: str,
        error_msg: str | None = None,
    ) -> None:
        values: dict[str, Any] = {"status": status}
        if status in ("completed", "failed"):
            values["completed_at"] = datetime.now(timezone.utc)
        if error_msg:
            values["error_msg"] = error_msg[:2048]
        async with self._sf() as sess:
            await sess.execute(
                update(EscalationRecord).where(EscalationRecord.id == record_id).values(**values)
            )
            await sess.commit()
```

"""EscalationExtractor — LLM-fill EscalationPacket draft from full chat history.

Per spec § 2.2 Update 2.  This is the central prompt-engineering deliverable
for Plan 3 (industrial problem **E9 LLM extraction quality**).

Design contract:
  Input
    - chat_session_id, chat_turn_count, chat_history_summary
    - history: list of {role, content} (full, post-context_node summarize)
    - cached_tool_results: list of {tool_name, tool_args, result_summary,
                                    cache_id, cached_at} from ToolResultCache
  Output
    - EscalationPacket draft with all 4 main classes filled
    - missing_field_hints emitted whenever the LLM is uncertain (E10)

Robustness:
  - JSON parse failure → minimal-fallback packet with a missing-field hint
    asking user to clarify intent (cf. test_extractor_json_parse_failure)
  - Hallucinated cache_id (not in cached_tool_results input) → filtered

The prompt (`_EXTRACTOR_PROMPT_TEMPLATE`) lives at module scope so Plan 5
golden case + future iterative tuning can A/B test prompt variants.
"""

from __future__ import annotations

import json
import logging
from datetime import datetime, timezone
from typing import Any

from app.agents.escalation_protocol import (
    ChatDerivedSignals,
    Entity,
    EscalationPacket,

    KnownFacts,
    MissingFieldHint,
    Preference,
    SessionMetadata,
    ToolResultRef,

logger = logging.getLogger(__name__)


_EXTRACTOR_PROMPT_TEMPLATE = """\
你是金融研究助手 chat→research 升级通道的「信号抽取员」。
用户在 chat 模式聊了多轮后,触发了「深度研报」按钮。你要看完整对话,
帮 ResearchAgent 准备好结构化的 EscalationPacket 草稿。
然后用户会确认/修改你写的草稿,所以**不确定的地方要标 missing_field_hints,
让用户来补充**,不要瞎猜。

==== 输入 ====

【chat session id】{chat_session_id}
【已聊的轮数】{chat_turn_count}
【历史摘要】(如果太长触发了 context_node 压缩;否则为空):
{chat_history_summary}

【完整对话历史】
{history_block}

【chat 期间已查过的工具结果(可被 research 跳过的)】
{cached_block}

==== 输出 ====

严格按下列 JSON 输出,不要任何额外文字、代码块或注释:
{{
  "explicit_task": {{
    "raw_last_user_turn": "...",       // 用户最后一句原文
    "extracted_intent": "...",         // 例: full_due_diligence / comparative_analysis / risk_assessment
    "target_ts_code": "..." or null,
    "target_entity_name": "..." or null,
    "user_extra_message": null
  }},
  "chat_derived_signals": {{
    "entities": [
      {{"name": "...", "ts_code": "..." or null,
        "role": "primary_target" | "comparative_target" | "mentioned_in_passing",
        "mention_turn_indices": [int, ...]}}
    ],
    "preferences": [
      {{"text": "...", "category": "risk_tolerance" | "focus_metric" | "comparative_focus" | "horizon" | "other",
        "confidence": float in [0, 1]}}
    ],
    "open_questions": ["...", ...],
    "inferred_persona": "..." or null,
    "extraction_confidence": float in [0, 1]
  }},
  "known_facts": {{
    "tool_results": [
      {{"tool_name": "...", "tool_args": {{...}}, "result_summary": "...",
        "cached_at": "ISO 8601", "cache_id": "..."}}
    ]
  }},
  "session_metadata": {{
    "chat_session_id": "{chat_session_id}",
    "chat_turn_count": {chat_turn_count},
    "chat_history_summary": ... or null,
    "user_confirmed_at": "{now_iso}",
    "user_edits": []
  }},
  "missing_field_hints": [
    {{"field_path": "explicit_task.target_ts_code",
      "reason": "llm_uncertain" | "schema_required_but_empty" | "user_skipped",
      "llm_question_for_user": "...问用户的话..."}}
  ]
}}

==== 工程约束 ====

1. **不许编造 cache_id** — 「known_facts.tool_results」里的 cache_id 必须严格来自上面【chat 期间已查过的工具结果】。
2. **不确定就标 missing_field_hints** — 例如用户说「ICBC」但没明确说「工商银行 / 601398.SH」,标 llm_uncertain。
3. **preferences 取证要看到** — 必须真在对话中能找到证据,不要从用户口吻凭空推断。
4. **extraction_confidence 反映自己的把握** — 信号清晰 0.8+,模糊 0.4-0.7,几乎没信息 < 0.3。
5. **mention_turn_indices** 用 0-based, 标实体在哪几轮被提到。

def _format_history(history: list[dict[str, Any]]) -> str:
    if not history:
        return "(空)"
    lines = []
    for i, t in enumerate(history):
        role = t.get("role", "?")
        content = (t.get("content") or "")[:500]
        lines.append(f"[turn {i}] {role}: {content}")
    return "\n".join(lines)


def _format_cached_tools(cached: list[dict[str, Any]]) -> str:
    if not cached:
        return "(无)"
    lines = []
    for c in cached:
        lines.append(
            f"- {c.get('tool_name')}({json.dumps(c.get('tool_args', {}), ensure_ascii=False)}) "
            f"→ {c.get('result_summary', '')[:200]}  [cache_id={c.get('cache_id')}]"
        )
    return "\n".join(lines)


def _now_iso() -> str:
    return datetime.now(timezone.utc).isoformat()


class EscalationExtractor:
    """LLM-driven EscalationPacket draft producer."""

    def __init__(self, llm: LLMService) -> None:
        self._llm = llm

    async def run(
        self,
        *,
        chat_session_id: str,
        chat_turn_count: int,
        chat_history_summary: str | None,
        history: list[dict[str, Any]],
        cached_tool_results: list[dict[str, Any]],
    ) -> EscalationPacket:
        prompt = _EXTRACTOR_PROMPT_TEMPLATE.format(
            chat_session_id=chat_session_id,
            chat_turn_count=chat_turn_count,
            chat_history_summary=chat_history_summary or "(无)",
            history_block=_format_history(history),
            cached_block=_format_cached_tools(cached_tool_results),
            now_iso=_now_iso(),
        )
        resp = self._llm.chat(prompt=prompt, tier="default", schema=None)

        try:
            data = json.loads(resp.text)
        except json.JSONDecodeError:
            logger.warning("EscalationExtractor: LLM returned non-JSON; minimal fallback")
            return self._minimal_fallback(
                chat_session_id, chat_turn_count, history, cached_tool_results,
            )

        # Filter hallucinated cache_id (must be in cached_tool_results input)
        valid_cache_ids = {c.get("cache_id") for c in cached_tool_results}
        if "known_facts" in data and "tool_results" in data["known_facts"]:
            data["known_facts"]["tool_results"] = [
                tr for tr in data["known_facts"]["tool_results"]
                if tr.get("cache_id") in valid_cache_ids
            ]

        try:
            return EscalationPacket.model_validate(data)
        except Exception as e:
            logger.warning("EscalationExtractor: Pydantic validation failed: %s", e)
            return self._minimal_fallback(
                chat_session_id, chat_turn_count, history, cached_tool_results,
            )

    def _minimal_fallback(
        self,
        chat_session_id: str,
        chat_turn_count: int,
        history: list[dict[str, Any]],
        cached_tool_results: list[dict[str, Any]],
    ) -> EscalationPacket:
        last_user = ""
        for t in reversed(history):
            if t.get("role") == "user":
                last_user = t.get("content", "")
                break
        return EscalationPacket(
            explicit_task=ExplicitTask(
                raw_last_user_turn=last_user,
                extracted_intent="unknown",
            ),
            chat_derived_signals=ChatDerivedSignals(
                entities=[], preferences=[], open_questions=[],
                inferred_persona=None, extraction_confidence=0.0,
            ),
            known_facts=KnownFacts(tool_results=[]),
            session_metadata=SessionMetadata(
                chat_session_id=chat_session_id,
                chat_turn_count=chat_turn_count,
                chat_history_summary=None,
                user_confirmed_at=datetime.now(timezone.utc),
                user_edits=[],
            ),
            missing_field_hints=[
                MissingFieldHint(
                    field_path="explicit_task.extracted_intent",
                    reason="llm_uncertain",
                    llm_question_for_user="抱歉, 我没能从对话中提取清晰的研究意图。请用一句话告诉我您想研究什么 (例如: '工商银行 (601398.SH) 的完整投资尽调')",
                ),
            ],
        )
```

def _summarize_report(markdown: str, max_chars: int = 200) -> str:
    """Trim report markdown to a one-card preview (E6 report token)."""
    if not markdown:
        return ""
    # Strip markdown headers / code fences for preview
    lines = [
        ln.strip().lstrip("# ").lstrip("> ")
        for ln in markdown.splitlines()
        if ln.strip() and not ln.startswith("```")
    ]
    text = " / ".join(lines[:5])
    return text[:max_chars]
```

async def run_streaming(
    self,
    user_input: str,
    request_id: str,
    *,
    state_overrides: dict[str, Any] | None = None,
) -> AsyncIterator[dict[str, Any]]:
    """Streams events; yields {event, data} dicts including a final
    {'event': '_final_sut_output', 'data': SUTOutput} entry."""
    config = {"configurable": {"thread_id": f"research:eval:{request_id}"}}
    initial = ResearchState(
        user_id="eval", session_id=request_id,
        user_message=user_input, request_id=request_id,
    )
    if state_overrides:
        for k, v in state_overrides.items():
            if hasattr(initial, k):
                setattr(initial, k, v)

    final_state: dict[str, Any] = {}
    async for chunk in self._graph.astream_events(
        initial.model_dump(), config=config, version="v2",
    ):
        kind = chunk.get("event", "")
        name = chunk.get("name", "")
        # Map LangGraph node lifecycle to our SSE event names
        if kind == "on_chain_end":

            elif name == "research_writer":
