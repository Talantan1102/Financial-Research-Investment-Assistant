# Roadmap #3.5 PR E — eval / EvalRecorder SQLite → PostgreSQL Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Migrate `EvalRecorder`(`eval_results` table)从 sqlite → PostgreSQL via SQLAlchemy ORM。Public API(`write` / `read` / `query`)不变,callers(`EvalRunner` / `Judge` / `cassette_validation.py`)不动。

**Architecture:** `eval_recorder.py`(90 行)的 raw sqlite3 cursor + `INSERT OR REPLACE` / `SELECT WHERE` 全部重写为 SQLAlchemy session 模式。新 `EvalResult` ORM model 加进 `models/`。`scores_json` text → JSONB(支持未来 `WHERE scores_json->'factuality'->'score' > 8` 这种 PG-native 查询)。`timestamp ISO text` → TIMESTAMP。

⚠️ **PR B 与 PR E 的耦合**:legacy 设计里 `trace_service` 跟 `EvalRecorder` 共享同一个 sqlite 文件(`backend/data/eval.sqlite`,不同表)。**PR B 已迁 spans 表 → PG**(若 PR B 先 ship);PR E 迁 `eval_results` 表。两个 PR 各自独立(不同表),无 hard 顺序依赖,但都 ship 后 `data/eval.sqlite` 文件就完全没用了 → 物理删。

**Tech Stack:** SQLAlchemy 2.0,PostgreSQL 15(JSONB for scores_json + TIMESTAMP for timestamp),保留 `EvalResult` Pydantic schema 不动(对 callers 透明)。

**Spec:** `docs/superpowers/specs/2026-05-07-roadmap-3.5-db-unify-design.md` § 4.4(eval)

**Prerequisites:** PR A merged。可以并行 PR B/C/D。

from sqlalchemy.dialects.postgresql import JSONB

from app.core.database import Base


class EvalResult(Base):
    """Single eval run result — Judge score + cost + latency."""

    __tablename__ = "eval_results"

    eval_id = Column(String(64), primary_key=True)
    request_id = Column(String(64), nullable=False, index=True)
    case_id = Column(String(128), nullable=False, index=True)
    scores_json = Column(JSONB().with_variant(JSON(), "sqlite"), nullable=False)
    judge_model = Column(String(64), nullable=False)
    judge_cost_cny = Column(Numeric(10, 4), nullable=False)
    judge_latency_ms = Column(Integer, nullable=False)
    timestamp = Column(DateTime(timezone=False), nullable=False)

```python
"""EvalRecorder — eval results persistence backed by PostgreSQL.

Roadmap #3.5 PR E — migrated from raw sqlite3 to SQLAlchemy ORM. Public
API preserved: write / read / query (caller-facing EvalResult Pydantic
schema unchanged).
"""

from __future__ import annotations

import json
from datetime import datetime
from typing import Any

from sqlalchemy import select
from sqlalchemy.orm import Session

from app.models.eval import EvalResult as EvalResultORM
from app.services.eval_models import EvalResult, JudgeScores


class EvalRecorder:
    def __init__(self, session: Session) -> None:
        self._session = session

    # init_schema() removed — alembic manages schema

    def write(self, result: EvalResult) -> None:
        """INSERT OR REPLACE — uses session.merge for upsert semantics."""
        orm = EvalResultORM(
            eval_id=result.eval_id,
            request_id=result.request_id,
            case_id=result.case_id,
            scores_json=result.scores.model_dump(),  # serialize Pydantic to dict (JSONB)
            judge_model=result.judge_model,
            judge_cost_cny=result.judge_cost_cny,
            judge_latency_ms=result.judge_latency_ms,
            timestamp=result.timestamp,
        )
        self._session.merge(orm)
        self._session.commit()

    def read(self, eval_id: str) -> EvalResult:
        """Read by eval_id — raises LookupError if not found."""
        orm = self._session.get(EvalResultORM, eval_id)
        if orm is None:
            raise LookupError(f"eval_id {eval_id} not found")
        return self._orm_to_result(orm)

    def query(self, filters: dict[str, Any]) -> list[EvalResult]:
        """Dynamic AND-joined filter on simple equality."""
        stmt = select(EvalResultORM)
        for k, v in filters.items():
            stmt = stmt.where(getattr(EvalResultORM, k) == v)
        rows = self._session.scalars(stmt).all()
        return [self._orm_to_result(orm) for orm in rows]

    @staticmethod
    def _orm_to_result(orm: EvalResultORM) -> EvalResult:
        # scores_json is dict (PG JSONB) or str (sqlite JSON variant) — handle both
        scores_data = orm.scores_json
        if isinstance(scores_data, str):
            scores_data = json.loads(scores_data)
        return EvalResult(
            eval_id=orm.eval_id,
            request_id=orm.request_id,
            case_id=orm.case_id,
            scores=JudgeScores(**scores_data),
            judge_model=orm.judge_model,
            judge_cost_cny=float(orm.judge_cost_cny),
            judge_latency_ms=orm.judge_latency_ms,
            timestamp=orm.timestamp,
        )
```
