# v0.9 Chat — Plan 2b: SkillExecutor Sandbox + L3b Script Execution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the L3b script execution layer for v0.9 chat skill progressive disclosure — a sandboxed `SkillExecutor` that runs Anthropic-style skill scripts (`scripts/X.py`) via subprocess with strict resource caps (memory / CPU / timeout / filesystem / network), JSON-over-stdio I/O contract, exit-code-driven success signal, and a static AST safety scan that rejects `os.system` / `subprocess` direct calls before launch. Wire L3b into the existing `SkillLoader` (Plan 2a) so SKILL.md `scripts/` references trigger execution rather than text load. Extend the `ChatPlanner` JSON output with an `execute_script` action and route it through `tool_node` to emit `skill_execute` SSE events. Ship one demo skill (`financial_analysis/scripts/calculate_dcf.py`) to validate the full pipeline end-to-end.

**Architecture:** Subprocess-isolated Python interpreter per script invocation; `cwd=skill_workdir/<run_id>/` ensures filesystem writes do not escape the sandbox; `resource.setrlimit(RLIMIT_AS, RLIMIT_CPU)` caps memory (256MB) and CPU (1 core); SIGKILL on timeout overrun (30s default / 5min max); stdin = JSON args, stdout = JSON result, stderr truncated to ≤ 2kB; exit code 0 = success, non-0 = `tool_error` SSE event; static AST scanner rejects banned APIs (`os.system`, `subprocess.Popen / .call / .run`, `socket.socket`, `urllib.request.urlopen`) at load time; subprocess `env` cleared to a minimal whitelist (`PATH` / `LANG` only) to neutralize ambient credentials; trusted skill root limited to `backend/claude_skills/`. `SkillLoader.detect_l3b()` returns `SkillScriptRef` objects; `ChatPlanner` emits `{"action": "execute_script", "skill": "X", "script": "scripts/Y.py", "args": {...}}`; `tool_node` invokes `SkillExecutor.execute()` and writes a `ToolResult(tool_name="skill_script", tool_call_data=...)` into `ChatState.tool_results`. SSE events `skill_execute_start` / `skill_execute_end` / `skill_execute_error` stream progress to frontend. Demo skill computes a discounted-cash-flow estimate from financials JSON.

**Tech Stack:** Python 3.11+ / `subprocess.Popen` / `resource.setrlimit` (POSIX only) / `signal.SIGKILL` / `ast` (stdlib AST scanner) / Pydantic / pytest + monkeypatch + tmp_path / FastAPI SSE wrapper from Plan 1 / DashScope LLM via legacy `LLMService.build_llm_service_from_env()`.

```python
"""Pydantic types for the SkillExecutor I/O contract (S7).

Wire format between the chat agent and the L3b script subprocess:

    stdin  ← JSON  (SkillScriptArgs.payload)
    stdout → JSON  (becomes SkillExecutionResult.stdout_json on success)
    stderr → text  (truncated to STDERR_MAX_BYTES; surfaced to LLM prompt)
    exit   → int   (0 = success; non-zero or negative = failure)

Path validation enforces the sandbox surface area at the type boundary so that
later code (executor / loader) can rely on `script_path` being well-formed.
"""

from __future__ import annotations

from pathlib import PurePosixPath
from typing import Any, Literal

from pydantic import BaseModel, Field, field_validator

ErrorKind = Literal[
    "timeout",
    "memory_limit",
    "cpu_limit",
    "non_zero_exit",
    "stdout_invalid_json",
    "safety_scan_rejected",
    "subprocess_launch_failed",
    "stderr_overflow",
]


class SkillScriptRef(BaseModel):
    """A reference to a script discovered inside a skill's directory.

    `script_path` is always relative to the skill root, must start with
    ``scripts/``, and may not contain `..` or absolute path components.
    """

    skill_name: str
    script_path: str
    description: str | None = None  # parsed from SKILL.md if available

    @field_validator("script_path")
    @classmethod
    def _validate_path(cls, v: str) -> str:
        p = PurePosixPath(v)
        if p.is_absolute():
            raise ValueError(f"script_path must be relative; got {v!r}")
        parts = p.parts
        if not parts or parts[0] != "scripts":
            raise ValueError(f"script_path must start with 'scripts/'; got {v!r}")
        if any(part == ".." for part in parts):
            raise ValueError(f"script_path may not contain '..'; got {v!r}")
        return v


class SkillScriptArgs(BaseModel):
    """Arbitrary JSON payload sent to the script via stdin."""

    payload: dict[str, Any] = Field(default_factory=dict)


class SkillExecutionError(BaseModel):
    """Error categorization surfaced through SSE and into the LLM prompt."""

    kind: ErrorKind
    message: str


class SkillExecutionResult(BaseModel):
    """Outcome of one SkillExecutor.execute() call."""

    ok: bool
    stdout_json: dict[str, Any] | None
    stderr_text: str  # already truncated to <=2kB
    exit_code: int
    elapsed_s: float
    skill_name: str
    script_path: str
    error: SkillExecutionError | None = None
```

"""Skill workdir — context-managed temp dir for L3b script execution.

Each invocation of SkillExecutor gets an isolated working directory under
``settings.SKILL_WORKDIR_ROOT/<run_id>-<suffix>/``.  The subprocess is launched
with ``cwd`` set to this dir; any files the script writes land here and are
removed on context exit.

The directory is always under the project tree (never `/tmp`) so that orphan
artifacts after a crash are obvious during dogfood.
"""

from __future__ import annotations

import contextlib
import shutil
import uuid
from collections.abc import Iterator
from pathlib import Path


@contextlib.contextmanager
def make_skill_workdir(*, run_id: str, root: Path | str) -> Iterator[Path]:
    """Create a unique workdir and clean it up on exit (success or exception)."""
    root_p = Path(root)
    root_p.mkdir(parents=True, exist_ok=True)
    suffix = uuid.uuid4().hex[:8]
    wd = root_p / f"{run_id}-{suffix}"
    wd.mkdir(parents=True, exist_ok=False)
    try:
        yield wd
    finally:
        shutil.rmtree(wd, ignore_errors=True)
```

Create `backend/app/skills/skill_executor.py`:

```python
"""SkillExecutor — sandboxed L3b script runner.

Per spec § 4.3 + § 5.1 S6/S7/S8/S9.

Pipeline:

    1. Resolve script_path under skills_root; reject if missing.
    2. (Task 8) AST safety scan — reject banned API references.
    3. Allocate workdir under workdir_root via skill_workdir.
    4. Launch subprocess.Popen(
         [python, script_full_path],
         cwd=workdir, env=_minimal_env(), preexec_fn=_apply_rlimits,
       )
    5. Pipe args.payload as JSON into stdin; close stdin.
    6. Wait up to timeout_s; on overrun SIGKILL the process group.
    7. Read stdout / stderr; truncate stderr to STDERR_MAX_BYTES.
    8. Parse stdout as JSON; populate SkillExecutionResult.
"""

from __future__ import annotations

import asyncio
import json
import os
import signal
import subprocess
import sys
import time
import uuid
from pathlib import Path
from typing import Final

from app.config import settings
from app.skills.script_schemas import (
    SkillExecutionError,
    SkillExecutionResult,
    SkillScriptArgs,
    SkillScriptRef,
)
from app.skills.skill_workdir import make_skill_workdir

# Whitelist for the subprocess env — everything else is dropped.
_ENV_WHITELIST: Final[frozenset[str]] = frozenset({"PATH", "LANG", "LC_ALL", "LC_CTYPE"})


def _minimal_env() -> dict[str, str]:
    """Return an env containing only whitelisted vars from the parent process."""
    return {k: v for k, v in os.environ.items() if k in _ENV_WHITELIST}


class SkillExecutor:
    """Sandboxed L3b script runner."""

    def __init__(
        self,
        *,
        skills_root: Path | str,
        workdir_root: Path | str,
        default_timeout_s: int | None = None,
        max_timeout_s: int | None = None,
        max_memory_mb: int | None = None,
        stderr_max_bytes: int | None = None,
    ) -> None:
        self._skills_root = Path(skills_root)
        self._workdir_root = Path(workdir_root)
        self._default_timeout_s = default_timeout_s or settings.SKILL_EXEC_DEFAULT_TIMEOUT_S
        self._max_timeout_s = max_timeout_s or settings.SKILL_EXEC_MAX_TIMEOUT_S
        self._max_memory_mb = max_memory_mb or settings.SKILL_EXEC_MAX_MEMORY_MB
        self._stderr_max_bytes = stderr_max_bytes or settings.SKILL_EXEC_STDERR_MAX_BYTES

    async def execute(
        self,
        *,
        ref: SkillScriptRef,
        args: SkillScriptArgs,
        timeout_s: int | None = None,
    ) -> SkillExecutionResult:
        timeout = min(timeout_s or self._default_timeout_s, self._max_timeout_s)
        script_full = self._skills_root / ref.skill_name / ref.script_path
        if not script_full.is_file():
            return _err_result(
                ref, exit_code=-1,
                err=SkillExecutionError(
                    kind="subprocess_launch_failed",
                    message=f"script not found: {script_full}",
                ),
            )

        run_id = uuid.uuid4().hex[:8]
        with make_skill_workdir(run_id=run_id, root=self._workdir_root) as wd:
            return await self._run_subprocess(ref, script_full, args, wd, timeout)

    async def _run_subprocess(
        self,
        ref: SkillScriptRef,
        script_full: Path,
        args: SkillScriptArgs,
        cwd: Path,
        timeout_s: int,
    ) -> SkillExecutionResult:
        # Resource limits applied in Task 4 via preexec_fn; for Task 3 we omit it.
        start = time.monotonic()
        try:
            proc = subprocess.Popen(
                [sys.executable, str(script_full)],
                cwd=str(cwd),
                env=_minimal_env(),
                stdin=subprocess.PIPE,
                stdout=subprocess.PIPE,
                stderr=subprocess.PIPE,
                start_new_session=True,
                # preexec_fn=_apply_rlimits(self._max_memory_mb, timeout_s),  # Task 4
            )
        except OSError as exc:
            return _err_result(
                ref, exit_code=-1,
                err=SkillExecutionError(
                    kind="subprocess_launch_failed", message=str(exc),
                ),
            )

        stdin_blob = json.dumps(args.payload).encode("utf-8")

        try:
            stdout_b, stderr_b = await asyncio.get_event_loop().run_in_executor(
                None,
                lambda: proc.communicate(input=stdin_blob, timeout=timeout_s),
            )
        except subprocess.TimeoutExpired:
            os.killpg(os.getpgid(proc.pid), signal.SIGKILL)
            stdout_b, stderr_b = proc.communicate()
            elapsed = time.monotonic() - start
            return SkillExecutionResult(
                ok=False, stdout_json=None,
                stderr_text=_truncate_stderr(stderr_b, self._stderr_max_bytes),
                exit_code=-9, elapsed_s=elapsed,
                skill_name=ref.skill_name, script_path=ref.script_path,
                error=SkillExecutionError(
                    kind="timeout",
                    message=f"exceeded {timeout_s}s",
                ),
            )

        elapsed = time.monotonic() - start
        stderr_text = _truncate_stderr(stderr_b, self._stderr_max_bytes)
        stdout_text = stdout_b.decode("utf-8", errors="replace") if stdout_b else ""

        if proc.returncode != 0:
            return SkillExecutionResult(
                ok=False, stdout_json=None,
                stderr_text=stderr_text, exit_code=proc.returncode,
                elapsed_s=elapsed,
                skill_name=ref.skill_name, script_path=ref.script_path,
                error=SkillExecutionError(
                    kind="non_zero_exit",
                    message=f"exit code {proc.returncode}",
                ),
            )

        try:
            stdout_json = json.loads(stdout_text) if stdout_text.strip() else None
        except json.JSONDecodeError as exc:
            return SkillExecutionResult(
                ok=False, stdout_json=None,
                stderr_text=stderr_text, exit_code=proc.returncode,
                elapsed_s=elapsed,
                skill_name=ref.skill_name, script_path=ref.script_path,
                error=SkillExecutionError(
                    kind="stdout_invalid_json",
                    message=f"could not parse stdout as JSON: {exc}",
                ),
            )

        return SkillExecutionResult(
            ok=True, stdout_json=stdout_json,
            stderr_text=stderr_text, exit_code=proc.returncode,
            elapsed_s=elapsed,
            skill_name=ref.skill_name, script_path=ref.script_path,
        )


def _truncate_stderr(data: bytes, max_bytes: int) -> str:
    if not data:
        return ""
    if len(data) <= max_bytes:
        return data.decode("utf-8", errors="replace")
    return data[:max_bytes].decode("utf-8", errors="replace") + "\n...[truncated]"


def _err_result(
    ref: SkillScriptRef, *, exit_code: int, err: SkillExecutionError
) -> SkillExecutionResult:
    return SkillExecutionResult(
        ok=False, stdout_json=None, stderr_text="", exit_code=exit_code,
        elapsed_s=0.0,
        skill_name=ref.skill_name, script_path=ref.script_path,
        error=err,
    )
```

import resource


def _apply_rlimits(*, memory_mb: int, cpu_seconds: int):
    """Build a preexec_fn closure that caps memory + CPU in the child process.

    Called inside the child process between fork() and exec().
    POSIX-only.  Raises ImportError on Windows; SkillExecutor is documented
    as POSIX-only.
    """

    def _set() -> None:
        soft_mem = memory_mb * 1024 * 1024
        # RLIMIT_AS = address space (closest portable approximation to "RAM cap").
        resource.setrlimit(resource.RLIMIT_AS, (soft_mem, soft_mem))
        # RLIMIT_CPU = total CPU time.  Fires SIGXCPU on overrun; we set hard
        # ceiling at 1.5x the soft so the child has a chance to clean up.
        soft_cpu = cpu_seconds
        hard_cpu = max(cpu_seconds + 5, int(cpu_seconds * 1.5))
        resource.setrlimit(resource.RLIMIT_CPU, (soft_cpu, hard_cpu))

    return _set

```python
"""Static AST safety scan for L3b skill scripts (S9).

This is defence-in-depth — even though the subprocess is sandboxed (cwd, env,
RLIMIT, no network on Linux), authors should not even *try* to use APIs that
could escape the sandbox or perform unintended side effects.

The scan is a static AST check.  It does NOT prevent runtime tricks (e.g.
``getattr(__builtins__, 'ev'+'al')``); those are mitigated by the subprocess
layer.  Banned APIs are tracked in ``BANNED_APIS`` so the README and the
scanner share one source of truth.

Detection strategy:
- ``ast.Import`` / ``ast.ImportFrom`` records aliased module names.
- ``ast.Call`` whose ``func`` resolves (via Name or Attribute chain) to a
  banned dotted name fires.
- Bare-name calls like ``eval(...)`` / ``exec(...)`` / ``__import__(...)``
  fire on Name node directly.
"""

from __future__ import annotations

import ast
from typing import Final

BANNED_APIS: Final[frozenset[str]] = frozenset({
    "os.system",
    "subprocess.Popen",
    "subprocess.call",
    "subprocess.run",
    "subprocess.check_call",
    "subprocess.check_output",
    "subprocess.getoutput",
    "subprocess.getstatusoutput",
    "socket.socket",
    "urllib.request.urlopen",
    "requests.get",
    "requests.post",
    "requests.put",
    "requests.delete",
    "requests.request",
    "httpx.get",
    "httpx.post",
    "httpx.put",
    "httpx.delete",
    "eval",
    "exec",
    "__import__",
})


class SafetyScanError(Exception):
    """Raised when a script contains a banned API reference."""


def scan_script_safety(source: str) -> None:
    """Parse `source` and raise SafetyScanError if any banned API is referenced."""
    try:
        tree = ast.parse(source)
    except SyntaxError as exc:
        raise SafetyScanError(f"syntax error: {exc}") from exc

    # Map alias → real module
    aliases: dict[str, str] = {}
    # Map alias of from-import → fully-qualified callable
    from_imports: dict[str, str] = {}

    for node in ast.walk(tree):
        if isinstance(node, ast.Import):
            for alias in node.names:
                key = alias.asname or alias.name
                aliases[key] = alias.name
        elif isinstance(node, ast.ImportFrom):
            mod = node.module or ""
            for alias in node.names:
                key = alias.asname or alias.name
                from_imports[key] = f"{mod}.{alias.name}" if mod else alias.name

    def _resolve_call(call_node: ast.Call) -> str | None:
        """Return the dotted-name of the callable, or None if undecidable."""
        f = call_node.func
        if isinstance(f, ast.Name):
            # Bare-name: eval, exec, __import__, OR alias of from-import.
            if f.id in from_imports:
                return from_imports[f.id]
            return f.id
        if isinstance(f, ast.Attribute):
            chain: list[str] = []
            cur: ast.expr = f
            while isinstance(cur, ast.Attribute):
                chain.append(cur.attr)
                cur = cur.value
            if isinstance(cur, ast.Name):
                base = aliases.get(cur.id, cur.id)
                chain.append(base)
                return ".".join(reversed(chain))
        return None

    for node in ast.walk(tree):
        if isinstance(node, ast.Call):
            resolved = _resolve_call(node)
            if resolved and resolved in BANNED_APIS:
                raise SafetyScanError(
                    f"banned API: {resolved} at line {node.lineno}"
                )
        # Bare-name access without call (e.g. `f = eval`) — also banned for
        # eval/exec/__import__.
        if isinstance(node, ast.Name) and node.id in {"eval", "exec", "__import__"}:
            # Only flag when not in import context
            if not isinstance(getattr(node, "ctx", None), ast.Store):
                # Check parent isn't an Import statement
                pass  # rely on Call detection above; skip bare-name to avoid false positives
```

import re
from pathlib import Path

from app.skills.script_schemas import SkillScriptRef


_SCRIPT_REF_PATTERN = re.compile(r"`(scripts/[A-Za-z0-9_\-./]+\.py)`\s*[—-]?\s*(.*)")


class SkillLoader:
    # ... existing methods (L1, L2, L3a) ...

    def detect_l3b_refs(self, skill_name: str) -> list[SkillScriptRef]:
        """Parse SKILL.md, extract every `scripts/X.py` mention along with its description."""
        skill_dir = Path(self._skills_root) / skill_name
        skill_md = skill_dir / "SKILL.md"
        if not skill_md.is_file():
            return []
        text = skill_md.read_text()

        refs: list[SkillScriptRef] = []
        seen: set[str] = set()
        for line in text.splitlines():
            m = _SCRIPT_REF_PATTERN.search(line)
            if not m:
                continue
            script_path = m.group(1)
            description = m.group(2).strip() or None
            if script_path in seen:
                continue
            full = skill_dir / script_path
            if not full.is_file():
                continue  # skip dead references
            seen.add(script_path)
            try:
                refs.append(SkillScriptRef(
                    skill_name=skill_name,
                    script_path=script_path,
                    description=description,
                ))
            except Exception:
                # Pydantic validation may reject e.g. paths with `..`
                continue
        return refs

"""DCF (Discounted Cash Flow) valuation script — L3b skill demo.

Wire format:
    stdin  ← JSON {
        "free_cash_flows": [num, ...],   # explicit-period FCF, year 1..N
        "wacc": float,                    # weighted avg cost of capital, e.g. 0.085
        "terminal_growth": float,         # perpetual growth rate, e.g. 0.025
        "shares_outstanding": int,        # diluted shares, units
        "net_debt": float                 # total debt - cash; can be negative
    }
    stdout → JSON {
        "enterprise_value": float,
        "equity_value": float,            # EV - net_debt
        "per_share": float,
        "terminal_value": float,
        "pv_of_terminal_value": float,
        "pv_of_explicit_fcfs": float,
        "horizon_years": int
    }

Run safely under SkillExecutor sandbox (cwd cap, RLIMIT_AS, RLIMIT_CPU,
no `os.system`, no `subprocess`, no network calls).
"""

from __future__ import annotations

import json
import sys
from typing import Any


def _validate(data: dict[str, Any]) -> dict[str, Any]:
    required = ["free_cash_flows", "wacc", "terminal_growth", "shares_outstanding", "net_debt"]
    for k in required:
        if k not in data:
            raise ValueError(f"missing field: {k}")
    fcfs = data["free_cash_flows"]
    if not isinstance(fcfs, list) or len(fcfs) == 0:
        raise ValueError("free_cash_flows must be a non-empty list of numbers")
    for f in fcfs:
        if not isinstance(f, (int, float)):
            raise ValueError(f"free_cash_flow not a number: {f!r}")
    for k in ("wacc", "terminal_growth", "net_debt"):
        if not isinstance(data[k], (int, float)):
            raise ValueError(f"{k} must be a number; got {type(data[k]).__name__}")
    if not isinstance(data["shares_outstanding"], int) or data["shares_outstanding"] <= 0:
        raise ValueError("shares_outstanding must be a positive int")
    if data["wacc"] <= data["terminal_growth"]:
        raise ValueError("wacc must exceed terminal_growth (Gordon constraint)")
    return data


def calculate_dcf(
    free_cash_flows: list[float],
    wacc: float,
    terminal_growth: float,
    shares_outstanding: int,
    net_debt: float,
) -> dict[str, float | int]:
    n = len(free_cash_flows)
    pv_explicit = 0.0
    for i, fcf in enumerate(free_cash_flows, start=1):
        pv_explicit += fcf / ((1 + wacc) ** i)

    fcf_n = free_cash_flows[-1]
    terminal_value = fcf_n * (1 + terminal_growth) / (wacc - terminal_growth)
    pv_terminal = terminal_value / ((1 + wacc) ** n)

    enterprise_value = pv_explicit + pv_terminal
    equity_value = enterprise_value - net_debt
    per_share = equity_value / shares_outstanding

    return {
        "enterprise_value": round(enterprise_value, 4),
        "equity_value": round(equity_value, 4),
        "per_share": round(per_share, 4),
        "terminal_value": round(terminal_value, 4),
        "pv_of_terminal_value": round(pv_terminal, 4),
        "pv_of_explicit_fcfs": round(pv_explicit, 4),
        "horizon_years": n,
    }


def main() -> int:
    try:
        raw = sys.stdin.read()
        data = json.loads(raw)
        data = _validate(data)
        out = calculate_dcf(
            free_cash_flows=data["free_cash_flows"],
            wacc=float(data["wacc"]),
            terminal_growth=float(data["terminal_growth"]),
            shares_outstanding=int(data["shares_outstanding"]),
            net_debt=float(data["net_debt"]),
        )
        print(json.dumps(out))
        return 0
    except (ValueError, KeyError, TypeError, json.JSONDecodeError) as exc:
        sys.stderr.write(f"calculate_dcf invalid input: {exc}\n")
        return 1


if __name__ == "__main__":
    sys.exit(main())
```

## Skill scripts (L3b sandbox)

The chat agent can execute Anthropic-style skill scripts (`backend/claude_skills/<skill>/scripts/X.py`)
through a sandboxed `SkillExecutor`.  Authors write a Python script that:

- reads JSON from stdin,
- prints a JSON result on stdout,
- writes any error explanation to stderr,
- exits 0 on success / non-zero on failure.

### Sandbox guarantees

| Surface | Guarantee |
|---|---|
| Filesystem | `cwd` is a fresh tmp dir under `backend/data/skill_workdir/` ; cleaned up after run |
| Memory | `RLIMIT_AS` cap of 256MB (configurable via `SKILL_EXEC_MAX_MEMORY_MB`) |
| CPU / wall time | 30s default / 5min max; SIGKILL on overrun |
| Environment | only `PATH` / `LANG` / `LC_*` passed through; no `DASHSCOPE_API_KEY` etc. |
| Banned APIs | `os.system`, `subprocess.{Popen,call,run,check_*,getoutput}`, `socket.socket`, `urllib.request.urlopen`, `requests.*`, `httpx.*`, `eval`, `exec`, `__import__` — rejected by static AST scan before launch |
| stdout / stderr | stderr truncated to 2kB; stdout must be valid JSON |

### Authoring a new script

1. Place under `backend/claude_skills/<skill>/scripts/<name>.py`.
2. Reference it in the skill's `SKILL.md` "Available scripts" section using a markdown bullet:
   ```markdown
   - `scripts/<name>.py` — short description for the planner LLM
   ```
3. Read stdin, write stdout, exit appropriately.
4. Add an L0 unit test under `backend/tests/unit/skills/`.
