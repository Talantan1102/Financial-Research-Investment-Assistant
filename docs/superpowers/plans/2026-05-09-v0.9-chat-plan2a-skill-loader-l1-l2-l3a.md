# v0.9 Chat — Plan 2a: Skill Loader L1 + L2 + L3a Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the L1 (skill name + description) → L2 (full SKILL.md) → L3a (resource files: yaml/json/md, no script execution) progressive-disclosure loader for the v0.9 ChatAgent. The loader feeds the constrained `ChatPlanner` LLM with a compact L1 list at session start, then expands to L2 / L3a on-demand when planner emits `{"action": "load_skill"}` or `{"action": "load_resource"}`. One demo skill (`risk_assessment`) gets a YAML resource (`risk_thresholds.yaml`) and an updated SKILL.md that references it via markdown link, exercising the full L1→L2→L3a loop end-to-end.

**Architecture:** Pure-Python `SkillLoader` service (no MCP, no subprocess, no sandbox — those are Plan 2b). Reads `backend/claude_skills/<name>/SKILL.md` frontmatter + body via filesystem; resources live under `<name>/resources/*.{yaml,json,md}`. Resource refs are detected by regex over markdown links to `resources/...`. 50kB hard cap per resource. Nested ref detection: depth ≤ 2 (SKILL.md → resource → resource is allowed; resource → resource → resource rejected). `ChatPlanner` system prompt is augmented with the L1 list; planner output schema gains two new action enum values: `load_skill` and `load_resource`. `context_node` (built in Plan 1) is extended to handle both actions and inject loaded text back into `ChatState.skill_context` for the next planner turn. Emits SSE `skill_load` events with `level=L2|L3a` + token count.

**Tech Stack:** Python 3.11+ / `pyyaml>=6.0` (already present transitively, verify) / `pydantic>=2.0` / `pytest` + `pytest-asyncio` (already present from Plan 1) / no new heavy deps. Re-uses Plan 1 hooks: `ChatPlanner` (constrained LLM), `ChatState` (Pydantic), `Memory` Protocol, `context_node` graph node, SSE event emitter in `backend/app/router/chat.py`.

```python
"""Pydantic types for SkillLoader (L1 / L2 / L3a layers).

Naming convention: S2 (描述工程) caps `description` at 512 chars to keep the
ChatPlanner system prompt bounded — at 7 skills × ~300 chars avg, the L1 block
is ~2.1kB (~500 tokens) which is sustainable across 10+ planner turns.

S5 (L3a size cap) is enforced by SkillLoader (not at type level) since it's a
load-time invariant rather than a structural one. Type carries `size_bytes` so
callers can verify post-hoc.
"""
from __future__ import annotations

import re
from typing import Literal

from pydantic import BaseModel, ConfigDict, Field, field_validator

_SNAKE_CASE_RE = re.compile(r"^[a-z][a-z0-9_]*$")


class SkillLoaderError(Exception):
    """Base for all SkillLoader-raised exceptions."""


class ResourceTooLargeError(SkillLoaderError):
    """Raised when an L3a resource exceeds the 50kB cap (S5)."""


class NestedDepthExceededError(SkillLoaderError):
    """Raised when nested resource refs exceed depth 2 (S4)."""


class SkillManifest(BaseModel):
    """L1 skill metadata — fits in ChatPlanner system prompt."""

    model_config = ConfigDict(frozen=True)

    name: str = Field(min_length=1, max_length=64)
    description: str = Field(min_length=1, max_length=512)
    path: str = Field(min_length=1)
    version: str = "1.0"
    tool_count: int = 0

    @field_validator("name")
    @classmethod
    def _name_snake_case(cls, v: str) -> str:
        if not _SNAKE_CASE_RE.match(v):
            raise ValueError(
                f"skill name must be snake_case (lowercase, digits, underscores), got: {v!r}"
            )
        return v


class SkillResource(BaseModel):
    """L3a resource content + metadata."""

    model_config = ConfigDict(frozen=True)

    name: str = Field(min_length=1)
    relative_path: str = Field(min_length=1)
    content_type: Literal["yaml", "json", "md"]
    content: str
    size_bytes: int = Field(ge=0)


class SkillLoadResult(BaseModel):
    """Result of `SkillLoader.load_skill(name)` — L2 + recursively-resolved L3a."""

    model_config = ConfigDict(frozen=True)

    name: str = Field(min_length=1)
    skill_md_content: str
    resources: list[SkillResource] = Field(default_factory=list)
    total_size_bytes: int = Field(ge=0)
    depth_used: int = Field(ge=1, le=2)
```

```python
"""SkillLoader — L1 list + L2 SKILL.md + L3a resource progressive disclosure.

Layer semantics:
- L1: name + description + version + tool_count, ~50-300 chars per skill.
  Loaded once at session start, injected into ChatPlanner system prompt.
- L2: full SKILL.md body (sans frontmatter), typically 5-30kB. Loaded when
  planner emits {"action": "load_skill"}.
- L3a: resource files (yaml/json/md) referenced by SKILL.md via markdown
  links matching `resources/...`. Loaded recursively up to depth 2 (S4),
  each file capped at 50kB (S5).
- L3b: scripts/*.py — NOT IMPLEMENTED in this plan, deferred to Plan 2b.

S1/S2 commitment: the L1 list is the only signal the planner LLM has when
deciding which skill to expand. SkillManifest enforces:
- name = snake_case (consistent identifier shape)
- description ≤ 512 chars (prompt budget cap)

S3 commitment: SKILL.md size is NOT capped at the loader (each individual
file is governed by writing-skills convention < 500 lines ≈ 30kB), but the
loader emits a warning log line if SKILL.md > 30kB so the writing process
can react.

S4 commitment: resource refs are walked breadth-first up to depth 2. Depth 1
= refs inside SKILL.md. Depth 2 = refs inside a depth-1 resource (only md
files; yaml/json don't contain markdown links). Depth 3 raises
NestedDepthExceededError.

S5 commitment: every resource is checked against the 50kB cap before being
returned in SkillLoadResult.

S10 commitment: SkillLoader exposes only static text — no execution, no
tool dispatch. Skill ↔ tool boundary: skills are LLM-readable docs +
optional scripts (Plan 2b); tools are MCP server endpoints (Plan 1). They
do not overlap.
"""
from __future__ import annotations

import logging
import re
from pathlib import Path

import yaml

from app.skills.types import (
    NestedDepthExceededError,
    ResourceTooLargeError,
    SkillLoaderError,
    SkillLoadResult,
    SkillManifest,
    SkillResource,
)

log = logging.getLogger(__name__)

# 50kB hard cap per L3a resource (S5).
RESOURCE_SIZE_CAP_BYTES = 50 * 1024
# Soft warning threshold for SKILL.md (S3).
SKILL_MD_WARN_BYTES = 30 * 1024
# Nested ref depth cap (S4) — counts SKILL.md as depth 1.
NESTED_DEPTH_CAP = 2

_FRONTMATTER_RE = re.compile(r"^---\s*\n(.*?)\n---\s*\n(.*)$", re.DOTALL)
# Markdown link to a path under `resources/...` — relative to skill root.
# Matches: [label](resources/foo.yaml) [label](./resources/foo.json)
_RESOURCE_LINK_RE = re.compile(r"\[[^\]]*\]\((?:\.\/)?(resources\/[^)\s]+)\)")


class SkillLoader:
    """Filesystem-backed skill metadata + content loader."""

    def __init__(self, skills_root: Path) -> None:
        self.skills_root = skills_root

    # --- L1 ----------------------------------------------------------------

    def load_l1(self) -> list[SkillManifest]:
        """Scan `skills_root/<name>/SKILL.md` and return frontmatter manifests."""
        if not self.skills_root.exists() or not self.skills_root.is_dir():
            return []

        out: list[SkillManifest] = []
        for child in sorted(self.skills_root.iterdir()):
            if not child.is_dir():
                continue
            skill_md = child / "SKILL.md"
            if not skill_md.exists():
                continue
            try:
                manifest = self._parse_frontmatter(child.name, skill_md)
            except SkillLoaderError as e:
                log.warning("skipping skill %s: %s", child.name, e)
                continue
            out.append(manifest)
        return out

    def _parse_frontmatter(self, dir_name: str, skill_md: Path) -> SkillManifest:
        text = skill_md.read_text(encoding="utf-8")
        m = _FRONTMATTER_RE.match(text)
        if not m:
            raise SkillLoaderError(f"no YAML frontmatter in {skill_md}")
        try:
            meta = yaml.safe_load(m.group(1))
        except yaml.YAMLError as e:
            raise SkillLoaderError(f"invalid YAML frontmatter in {skill_md}: {e}") from e
        if not isinstance(meta, dict):
            raise SkillLoaderError(f"frontmatter not a mapping in {skill_md}")

        name = meta.get("name", dir_name)
        description = (meta.get("description") or "").strip()
        if not description:
            raise SkillLoaderError(f"empty description in {skill_md}")

        return SkillManifest(
            name=name,
            description=description,
            path=str(skill_md.parent),
            version=str(meta.get("version", "1.0")),
            tool_count=int(meta.get("tool_count", 0)),
        )
```

```python
    @staticmethod
    def _detect_resource_refs(text: str) -> list[str]:
        """Return de-duplicated list of `resources/*` refs in markdown text.

        S4: this is the foundation of nested-depth tracking. Resources can
        themselves contain refs (only md files in practice; yaml/json don't
        carry markdown). Caller walks BFS up to depth 2.

        Matches both bare `(resources/foo.yaml)` and `(./resources/foo.yaml)`
        — relative-to-skill-root only. External URLs and refs to non-resources/
        dirs are ignored.
        """
        seen: set[str] = set()
        out: list[str] = []
        for m in _RESOURCE_LINK_RE.finditer(text):
            ref = m.group(1)
            if ref not in seen:
                seen.add(ref)
                out.append(ref)
        return out
```

```python
    _CONTENT_TYPE_BY_EXT: dict[str, str] = {
        ".yaml": "yaml",
        ".yml": "yaml",
        ".json": "json",
        ".md": "md",
    }

    def _load_one_resource(self, skill_name: str, relative_ref: str) -> SkillResource:
        """Read a single resource file under `skills_root/<skill>/<relative_ref>`.

        Enforces:
        - relative_ref MUST start with "resources/" — protects against the
          attacker case where SKILL.md is mutated to ref `../private.txt`.
        - resolved path MUST stay inside `skills_root/<skill>/resources/` —
          even after symlink resolution. Path traversal raises SkillLoaderError.
        - file extension MUST be .yaml/.yml/.json/.md (S5 indirect: caps the
          content surface area).
        - file size MUST be ≤ 50kB (S5).

        S5: cap is 50 * 1024 bytes inclusive. 50kB+1 byte raises
        ResourceTooLargeError.
        """
        if not relative_ref.startswith("resources/"):
            raise SkillLoaderError(
                f"invalid resource ref (must start with 'resources/'): {relative_ref!r}"
            )

        skill_root = (self.skills_root / skill_name).resolve()
        resources_root = (skill_root / "resources").resolve()
        target = (skill_root / relative_ref).resolve()

        # Path traversal guard: target MUST be under resources/.
        try:
            target.relative_to(resources_root)
        except ValueError as e:
            raise SkillLoaderError(
                f"path traversal blocked: {relative_ref!r} escapes resources/"
            ) from e

        if not target.exists() or not target.is_file():
            raise SkillLoaderError(f"resource not found: {relative_ref}")

        ext = target.suffix.lower()
        ct = self._CONTENT_TYPE_BY_EXT.get(ext)
        if ct is None:
            raise SkillLoaderError(
                f"unsupported resource extension {ext!r} (allowed: .yaml/.yml/.json/.md)"
            )

        size = target.stat().st_size
        if size > RESOURCE_SIZE_CAP_BYTES:
            raise ResourceTooLargeError(
                f"resource {relative_ref} is {size} bytes, exceeds 50kB cap "
                f"({RESOURCE_SIZE_CAP_BYTES} bytes)"
            )

        content = target.read_text(encoding="utf-8")
        return SkillResource(
            name=target.stem,
            relative_path=relative_ref,
            content_type=ct,  # type: ignore[arg-type]
            content=content,
            size_bytes=size,
        )
```

```python
    def load_skill(self, name: str) -> SkillLoadResult:
        """Load SKILL.md + recursively-referenced L3a resources for `name`.

        BFS walk:
        - depth 1 = SKILL.md body
        - depth 2 = resources referenced from SKILL.md (yaml/json/md)
        - depth 3 = refs from a depth-2 .md resource — REJECTED
                    (yaml/json have no markdown link syntax, so they
                    cannot trigger this in practice, but a malicious
                    or misauthored .md resource would.)

        Raises:
        - SkillLoaderError if skill missing
        - ResourceTooLargeError if any resource > 50kB (S5)
        - NestedDepthExceededError if depth > 2 (S4)
        """
        skill_md_body = self.load_skill_md(name)
        depth_used = 1
        resources: list[SkillResource] = []

        # depth-1 refs (from SKILL.md)
        depth1_refs = self._detect_resource_refs(skill_md_body)
        if not depth1_refs:
            return SkillLoadResult(
                name=name,
                skill_md_content=skill_md_body,
                resources=[],
                total_size_bytes=len(skill_md_body.encode("utf-8")),
                depth_used=1,
            )

        # Walk depth-1 → depth-2.
        depth_used = 2
        for ref in depth1_refs:
            r = self._load_one_resource(name, ref)
            resources.append(r)
            # If this depth-1 resource is markdown, scan it for nested refs.
            # Any nested ref means depth would become 3 — reject.
            if r.content_type == "md":
                nested = self._detect_resource_refs(r.content)
                if nested:
                    raise NestedDepthExceededError(
                        f"depth 3 > cap {NESTED_DEPTH_CAP} at {ref!r} "
                        f"(found {len(nested)} nested ref(s) in markdown resource)"
                    )

        total = len(skill_md_body.encode("utf-8")) + sum(r.size_bytes for r in resources)
        return SkillLoadResult(
            name=name,
            skill_md_content=skill_md_body,
            resources=resources,
            total_size_bytes=total,
            depth_used=depth_used,
        )

    # --- L3a single-resource external API ----------------------------------

    def load_resource(self, skill_name: str, relative_ref: str) -> SkillResource:
        """Public API: load one resource without walking SKILL.md.

        Used when planner emits {"action": "load_resource", "skill": "X",
        "ref": "resources/foo.yaml"} — i.e., user already has L2 loaded and
        wants to drill into a specific resource without re-reading SKILL.md.
        """
        return self._load_one_resource(skill_name, relative_ref)
```

```python
from app.skills import SkillManifest


def build_skill_list_block(skills: list[SkillManifest]) -> str:
    """Render the L1 skill list as a markdown block for the planner system prompt.

    Format:
        ## Available Skills

        - **risk_assessment**: Investment risk assessment.
        - **financial_analysis**: ...

        To expand a skill, emit {"action": "load_skill", "name": "<n>"}.
        To load a specific resource within a loaded skill, emit
        {"action": "load_resource", "skill": "<n>", "ref": "resources/<file>"}.

    S2 commitment: this is the only signal the planner has about each skill's
    capability. Description quality determines retrieval accuracy. The block
    is sorted by name (deterministic ordering — caching-friendly + reproducible
    eval). Empty input returns empty string so callers can skip injection.
    """
    if not skills:
        return ""

    lines = ["## Available Skills", ""]
    for s in sorted(skills, key=lambda x: x.name):
        # Strip newlines in description — planner prompt is line-sensitive.
        desc = s.description.replace("\n", " ").strip()
        lines.append(f"- **{s.name}**: {desc}")
    lines.extend(
        [
            "",
            'To expand a skill, emit {"action": "load_skill", "name": "<n>"}.',
            'To load a specific resource within a loaded skill, emit '
            '{"action": "load_resource", "skill": "<n>", "ref": "resources/<file>"}.',
        ]
    )
    return "\n".join(lines)
```

```python
import logging

from app.agents.chat_planner import ChatPlannerAction, ChatPlannerDecision
from app.agents.schemas import ChatState
from app.skills import (
    NestedDepthExceededError,
    ResourceTooLargeError,
    SkillLoaderError,
)
from app.skills.skill_loader import SkillLoader

log = logging.getLogger(__name__)


def _format_resources_block(skill_md_body: str, resources: list) -> str:
    """Concatenate SKILL.md + each resource into one text bundle for prompt injection."""
    parts: list[str] = [skill_md_body]
    for r in resources:
        parts.append(
            f"\n\n## Resource: {r.relative_path} ({r.content_type}, {r.size_bytes} bytes)\n\n"
            f"```{r.content_type}\n{r.content}\n```"
        )
    return "".join(parts)


def handle_skill_load_action(
    state: ChatState,
    decision: ChatPlannerDecision,
    loader: SkillLoader,
) -> ChatState:
    """Handle planner's `load_skill` action — populate ChatState.skill_context.

    Idempotent: if skill already loaded, returns state unchanged.
    Graceful degrade on error: malformed/missing skill → log + return unchanged
    so the graph can re-prompt the planner with an error hint.

    S10: skill content is treated as text only. No tool dispatch, no script
    execution. The skill bundle joins the planner's prompt context for the
    next turn — that's the entire effect.
    """
    if decision.action != ChatPlannerAction.LOAD_SKILL:
        return state
    name = decision.name
    if not name:
        return state
    if name in state.skill_context:
        # Idempotent — already loaded.
        return state

    try:
        result = loader.load_skill(name)
    except (SkillLoaderError, ResourceTooLargeError, NestedDepthExceededError) as e:
        log.warning("load_skill(%s) failed: %s", name, e)
        return state

    bundle = _format_resources_block(result.skill_md_content, result.resources)
    new_ctx = dict(state.skill_context)
    new_ctx[name] = bundle
    return state.model_copy(update={"skill_context": new_ctx})


def handle_resource_load_action(
    state: ChatState,
    decision: ChatPlannerDecision,
    loader: SkillLoader,
) -> ChatState:
    """Handle planner's `load_resource` action — append one resource to existing skill context.

    Precondition: skill must already be in state.skill_context (planner should
    only call load_resource AFTER load_skill). If skill missing, no-op.

    S5/S10: resource is loaded via SkillLoader.load_resource, which enforces
    50kB cap + path traversal guard. Failures are graceful — state unchanged
    + warning log.
    """
    if decision.action != ChatPlannerAction.LOAD_RESOURCE:
        return state
    skill = decision.skill
    ref = decision.ref
    if not skill or not ref:
        return state
    if skill not in state.skill_context:
        # Planner asked for a resource on a not-yet-loaded skill. No-op.
        log.warning(
            "load_resource on unloaded skill %s — planner should load_skill first",
            skill,
        )
        return state

    try:
        r = loader.load_resource(skill, ref)
    except (SkillLoaderError, ResourceTooLargeError) as e:
        log.warning("load_resource(%s, %s) failed: %s", skill, ref, e)
        return state

    appended = (
        state.skill_context[skill]
        + f"\n\n## Resource: {r.relative_path} ({r.content_type}, {r.size_bytes} bytes)\n\n"
        + f"```{r.content_type}\n{r.content}\n```"
    )
    new_ctx = dict(state.skill_context)
    new_ctx[skill] = appended
    return state.model_copy(update={"skill_context": new_ctx})
```

```python
# Approximate token count: 1 token ≈ 4 bytes (UTF-8) for mixed CJK + English.
# Cheap heuristic — exact count would require tiktoken roundtrip per chunk.
def _approx_tokens(text: str) -> int:
    return len(text.encode("utf-8")) // 4


async def skill_load_node(state: ChatState, config: dict) -> dict:
    loader = config["configurable"]["skill_loader"]
    writer = config.get("writer")  # type: ignore[assignment]
    decision = state.last_planner_decision
    new_state = handle_skill_load_action(state, decision, loader)

    # Emit skill_load SSE event if loading actually happened (skill_context grew).
    if decision and decision.name and decision.name not in state.skill_context \
            and decision.name in new_state.skill_context:
        loaded_text = new_state.skill_context[decision.name]
        if writer is not None:
            writer({
                "type": "skill_load",
                "name": decision.name,
                "level": "L2",  # L2 = SKILL.md + (any L3a resources auto-resolved during load_skill)
                "size_tokens": _approx_tokens(loaded_text),
            })
    return {"skill_context": new_state.skill_context}


async def resource_load_node(state: ChatState, config: dict) -> dict:
    loader = config["configurable"]["skill_loader"]
    writer = config.get("writer")
    decision = state.last_planner_decision
    new_state = handle_resource_load_action(state, decision, loader)

    if decision and decision.skill and decision.ref:
        before = state.skill_context.get(decision.skill, "")
        after = new_state.skill_context.get(decision.skill, "")
        delta = after[len(before):]
        if delta and writer is not None:
            writer({
                "type": "skill_load",
                "name": decision.skill,
                "level": "L3a",
                "ref": decision.ref,
                "size_tokens": _approx_tokens(delta),
            })
    return {"skill_context": new_state.skill_context}
```

```python
"""S1 quantitative benchmark: given user query → mocked LLM picks the right skill.

The "LLM" here is a deterministic keyword-matching stub that simulates a
constrained-output LLM choosing one of the 7 skills based on a system prompt
containing the L1 list. It's not a real LLM benchmark (that would need
cassettes + cost), but it ensures:
  - L1 descriptions contain enough discriminative keywords
  - No two skills have overlapping primary signals on these 10 queries

Top-1 accuracy threshold: 90% (9/10 minimum). Fixtures are drawn from the
"When to use" sections of each SKILL.md.
"""
from __future__ import annotations

import re
from pathlib import Path

import pytest

from app.skills.skill_loader import SkillLoader

# 10 user-style queries → expected skill name. Drawn from SKILL.md "When to
# use" sections to keep the benchmark anchored to authored intent.
FIXTURES: list[tuple[str, str]] = [
    ("茅台股价多少", "market_data"),
    ("贵州茅台的财务状况怎么样", "financial_analysis"),
    ("半导体行业有哪些龙头股", "sector_analysis"),
    ("帮我深度分析一下宁德时代", "deep_research"),
    ("茅台和五粮液对比一下技术面", "data_analysis"),
    ("最近平安银行有什么新闻", "web_research"),
    ("贵州茅台风险大不大,适合保守投资者吗", "risk_assessment"),
    ("帮我画一下茅台的 K 线图数据", "data_analysis"),
    ("北向资金最近流入哪些股票", "market_data"),
    ("生成一份贵州茅台的投资研报", "deep_research"),
]


def _stub_llm_pick(query: str, skill_descriptions: dict[str, str]) -> str:
    """Deterministic keyword-overlap scorer.

    Splits query and each description into Chinese 2-grams + English tokens,
    ranks skills by overlap. Highest score wins. Ties broken alphabetically
    (deterministic).
    """

    def tokens(text: str) -> set[str]:
        # English words + Chinese 2-grams.
        text = text.lower()
        eng = set(re.findall(r"[a-z]{2,}", text))
        # Strip non-CJK
        cjk = re.sub(r"[^一-鿿]", "", text)
        bigrams = {cjk[i : i + 2] for i in range(len(cjk) - 1)}
        return eng | bigrams

    q_tokens = tokens(query)
    scores: dict[str, int] = {}
    for name, desc in skill_descriptions.items():
        d_tokens = tokens(desc)
        scores[name] = len(q_tokens & d_tokens)
    # Sort by (-score, name)
    return sorted(scores.items(), key=lambda kv: (-kv[1], kv[0]))[0][0]


@pytest.fixture
def descriptions() -> dict[str, str]:
    repo_root = Path(__file__).resolve().parents[3]
    loader = SkillLoader(skills_root=repo_root / "claude_skills")
    return {m.name: m.description for m in loader.load_l1()}


def test_l1_retrieval_top1_ge_90_percent(descriptions: dict[str, str]) -> None:
    if not descriptions:
        pytest.skip("real claude_skills/ not present")

    correct = 0
    misses: list[tuple[str, str, str]] = []
    for query, expected in FIXTURES:
        picked = _stub_llm_pick(query, descriptions)
        if picked == expected:
            correct += 1
        else:
            misses.append((query, expected, picked))

    accuracy = correct / len(FIXTURES)
    assert accuracy >= 0.90, (
        f"L1 top-1 accuracy {accuracy:.0%} < 90%. Misses: {misses}\n"
        f"Suggested fixes: enrich descriptions of mis-picked skills with the "
        f"primary signal keywords from the 'When to use' bullets."
    )


def test_l1_descriptions_are_distinguishable(descriptions: dict[str, str]) -> None:
    """No two skills should have ≥ 80% token overlap in description (S2)."""
    if not descriptions:
        pytest.skip("real claude_skills/ not present")

    def tokens(text: str) -> set[str]:
        text = text.lower()
        eng = set(re.findall(r"[a-z]{2,}", text))
        cjk = re.sub(r"[^一-鿿]", "", text)
        bigrams = {cjk[i : i + 2] for i in range(len(cjk) - 1)}
        return eng | bigrams

    items = list(descriptions.items())
    for i in range(len(items)):
        for j in range(i + 1, len(items)):
            a_name, a_desc = items[i]
            b_name, b_desc = items[j]
            a_tok = tokens(a_desc)
            b_tok = tokens(b_desc)
            if not a_tok or not b_tok:
                continue
            overlap = len(a_tok & b_tok) / min(len(a_tok), len(b_tok))
            assert overlap < 0.80, (
                f"description overlap between {a_name} and {b_name} is "
                f"{overlap:.0%} ≥ 80% — descriptions should be more distinguishable"
            )
```
