用户把 Financial-Research-Investment-Assistant 项目定位为**个人作品/portfolio**,不是完全生产级,但希望它能**体现自己在 LLM 算法 + LLM 应用设计开发上的技术深度**。

含义:
- 砍掉冗余实现优先级高于"保兼容";不必要的 enterprise 抽象(多租户、复杂权限、灰度)是负资产。
- 但留下来的主路径必须有"可讲性" —— 每个组件能让读者/面试官看出这里用了什么 LLM 技术、为什么这么设计、做了哪些非显然的选择。
- Mock 服务、单进程部署、简化运维是可以接受的。
