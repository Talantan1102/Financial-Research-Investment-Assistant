# 结论

v1.x A5b ship 完(代码层 + 生产 wire 双完成):**2-round bull/bear adversarial debate
+ Critic 第 8 维 dialectical_balance + Writer prompt cross-check block + retry edge
trigger**。Debate 站在 A5a 数字层之上(advocate prompt 引 dcf_bull/dcf_bear/outlier_diagnosis)。

工程量 ~1100 行 / 8 commits(spec / plan / Task 1-8)/ ~10 文件改动。

# Why

A5a 防数字 hallucination 后,LLM 单 prompt 仍有 confirmation bias → narrative 一面之词。
A5b 用 2 advocate 各 30% 立场 + 2 轮 rebut + Writer 综合的 multi-agent debate 工业范式
强制双向论证。"双 hallucination 防御"故事至此完整闭环。

# 一句话总结

Bull/Bear 各 30% 立场 fast tier × 2 轮 rebut → Writer balanced tier 综合 → Critic 第 8 维
dialectical_balance rule-based 守护 → retry edge < 7.0 trigger。

# Architecture

```
Analyst (sync,LLM call insight)
├── _maybe_compute_valuation_analysis (A5a)
└── _maybe_run_debate (A5b)
       └── DebateOrchestrator (asyncio.gather + fallback ladder)
            ├── Round 1 (parallel): BullAdvocate.advocate_round_1 / BearAdvocate.advocate_round_1
            └── Round 2 (parallel): BullAdvocate.advocate_round_2(state, bear_v1) / BearAdvocate(state, bull_v1)

Writer (balanced tier)
├── build_investment_dd_prompt
│   ├── _format_cross_check_block (A5a)
│   └── _format_debate_block (A5b) — narrative 必须 ≥2 bull + ≥2 bear,引 strongest_*
├── LLM call schema=InvestmentDueDiligenceReport
└── post_process_writer_output
    ├── classify_recommendation (v0.8.5 Python deterministic)
    ├── compute_position_size_pct (v0.8.5)
    ├── valuation_analysis 拷 (A5a)
    └── debate 拷 (A5b): bull_case / bear_case / strongest_*_point 进 InvestmentRecommendation

Critic 8 维 fan-out (critic_subgraph)
├── 6 既有 LLM scorer (factuality / coverage / insight / structure / conciseness / input_context)
├── valuation_consistency (A5a, rule-based)
└── dialectical_balance (A5b, rule-based)

Writer retry edge (_writer_retry_router OR 3 trigger)
├── factuality < 7.0 (v1.x A4)
├── valuation_consistency < 7.0 (A5a Task 17)
└── dialectical_balance < 7.0 (A5b Task 8)
```
