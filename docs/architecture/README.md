## 核心组件

### 1. ChiefArchitect（规划架构师）

- **职责**：理解用户查询，生成研究大纲
- **输入**：用户查询字符串
- **输出**：结构化研究计划

### 2. DeepScout（深度侦察员）

- **职责**：并行执行多个搜索任务
- **输入**：研究计划
- **输出**：搜索结果集合

### 3. DataAnalyst（数据分析师）

- **职责**：分析数据模式，生成可视化
- **输入**：搜索结果
- **输出**：分析结论 + 图表

### 4. LeadWriter（主笔）

- **职责**：整合信息，撰写研究报告
- **输入**：分析结果
- **输出**：结构化报告

### 5. CriticMaster（审核员）

- **职责**：对抗式审查，指出遗漏
- **输入**：报告草稿
- **输出**：审核意见

## 状态管理

使用 LangGraph 管理研究状态：

```python
class ResearchState(TypedDict):
    query: str                    # 原始问题
    phase: ResearchPhase          # 当前阶段
    plan: Dict[str, Any]          # 研究计划
    findings: List[Dict]          # 发现的数据
    analysis: Dict[str, Any]      # 分析结果
    report: str                   # 报告内容
    feedback: Optional[str]       # 审核反馈
    iteration: int                # 迭代次数
```

## 技术选型

| 组件 | 技术 | 选型理由 |
|------|------|----------|
| LLM | 阿里云百炼 (Qwen) | 国内合规、成本可控 |
| 框架 | LangGraph | 显式状态管理、多智能体协作 |
| 向量库 | Milvus | 高性能、支持混合检索 |
| 数据库 | PostgreSQL | 关系数据 + JSONB 灵活存储 |
| 后端 | FastAPI | 异步支持好、自动生成文档 |
| 前端 | React + Vite | 组件化、流式渲染支持 |
