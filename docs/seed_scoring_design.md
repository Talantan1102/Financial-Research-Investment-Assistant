# Seed 质量多维度评分方案 v1.0

**设计目的**: 对 9,689 个 Seed 进行自动化质量评估，筛选高质量训练数据  
**评分方式**: LLM (qwen-max) 自动评分 + 规则校验  
**输出**: 每个 Seed 的详细评分 + 质量分级标签

---

## 1. 评分维度设计

### 1.1 核心维度（5个）

| 维度 | 权重 | 评分标准 | 说明 |
|------|------|---------|------|
| **自然度** | 25% | 0-10分 | 是否像真实人类提问 |
| **相关性** | 20% | 0-10分 | 与槽位标签的匹配程度 |
| **完整性** | 15% | 0-10分 | 信息是否完整可回答 |
| **合规性** | 20% | 0-10分 | 无幻觉/无敏感内容 |
| **实用性** | 15% | 0-10分 | 对训练的价值 |

### 1.2 维度详细定义

#### 维度1: 自然度 (Naturalness)

**定义**: 问题是否像真实用户会问的，语言是否自然流畅

**评分细则**:
- **10分**: 非常自然，完全像真人提问，有口语化特征
- **8-9分**: 自然，偶有机器感但不影响理解
- **6-7分**: 一般，有明显模板痕迹
- **4-5分**: 不自然，机器味重
- **0-3分**: 明显机器生成，不像人话

**检查点**:
- [ ] 用词符合用户类型（小白用词简单，机构用词专业）
- [ ] 语序自然，无明显语法错误
- [ ] 有真实用户特征（情绪、背景、口语化）

#### 维度2: 相关性 (Relevance)

**定义**: 生成内容与槽位标签的匹配程度

**评分细则**:
- **10分**: 完美匹配，所有槽位特征都体现在内容中
- **8-9分**: 高度匹配，大部分槽位特征体现
- **6-7分**: 基本匹配，部分槽位特征缺失
- **4-5分**: 匹配度低，槽位与内容不符
- **0-3分**: 完全不匹配，内容与槽位无关

**检查点**:
- [ ] 用户类型匹配（小白不会问太专业的问题）
- [ ] 意图匹配（问买卖的问题确实是买卖相关）
- [ ] 场景匹配（深套中的问题体现焦虑情绪）
- [ ] 风格匹配（情绪化的确实有情绪表达）

#### 维度3: 完整性 (Completeness)

**定义**: 问题信息是否完整，模型能否理解并回答

**评分细则**:
- **10分**: 信息完整，无需追问即可回答
- **8-9分**: 基本完整，少量信息缺失但不影响回答
- **6-7分**: 部分缺失，需要追问才能回答
- **4-5分**: 严重缺失，无法理解用户意图
- **0-3分**: 信息极度缺失或混乱

**检查点**:
- [ ] 涉及的股票/行业明确（如有实体）
- [ ] 问题意图清晰
- [ ] 必要的上下文已提供（持仓、成本等）

#### 维度4: 合规性 (Compliance)

**定义**: 是否符合安全规范，无幻觉、无敏感内容

**评分细则**:
- **10分**: 完全合规，无任何问题
- **8-9分**: 基本合规，轻微问题但不影响
- **6-7分**: 有轻微违规（如轻微歧义）
- **4-5分**: 中度违规（如出现涨跌描述）
- **0-3分**: 严重违规（政治敏感、色情、违法）

**检查点**:
- [ ] 无市场走势编造（"一直跌"、"涨得好"）
- [ ] 无价格预测（"明天涨到xxx"）
- [ ] 无敏感政治内容
- [ ] 无色情/广告/骚扰内容
- [ ] 无内幕消息请求

#### 维度5: 实用性 (Utility)

**定义**: 对训练金融对话模型的价值

**评分细则**:
- **10分**: 极高价值，覆盖重要场景
- **8-9分**: 高价值，有助于模型学习
- **6-7分**: 一般价值，可训练但非核心
- **4-5分**: 低价值，对训练帮助不大
- **0-3分**: 无价值或负面价值

**评估标准**:
- 是否覆盖高频用户场景
- 是否有助于模型理解用户意图
- 是否有助于模型学习槽位匹配

## 2. 评分方法

### 2.1 LLM 评分 Prompt 设计

```python
SCORING_PROMPT = """你是一位专业的金融对话数据质量评估专家。请对以下投资咨询问题进行多维度评分。

【待评估问题】
{content}

【标签信息】
- 用户类型: {user_type}
- 意图: {intent}
- 场景: {context}
- 风格: {style}
- 实体: {entities}

【评分维度】
请从以下5个维度进行评分（0-10分，10分为最佳）：

1. **自然度**: 是否像真实用户会问的？语言是否自然？
   - 10分: 非常自然，完全像真人
   - 5分: 一般，有机器感
   - 0分: 明显机器生成

2. **相关性**: 与槽位标签的匹配程度？
   - 10分: 完美匹配所有标签
   - 5分: 部分匹配
   - 0分: 完全不匹配

3. **完整性**: 信息是否完整可回答？
   - 10分: 完整，无需追问
   - 5分: 部分缺失
   - 0分: 极度缺失

4. **合规性**: 有无幻觉/敏感内容？
   - 10分: 完全合规
   - 5分: 轻微违规（如编造涨跌）
   - 0分: 严重违规

5. **实用性**: 对训练的价值？
   - 10分: 极高价值
   - 5分: 一般价值
   - 0分: 无价值

【输出格式】
请以JSON格式输出评分结果：
```json
{{
  "naturalness": 8,
  "naturalness_comment": "语言自然，像真实散户提问",
  "relevance": 9,
  "relevance_comment": "与槽位标签高度匹配",
  "completeness": 7,
  "completeness_comment": "信息基本完整",
  "compliance": 10,
  "compliance_comment": "无违规内容",
  "utility": 8,
  "utility_comment": "对训练有价值",
  "overall": 8.0,
  "overall_comment": "总体质量良好",
  "quality_level": "high"
}}
```

quality_level 请根据 overall 分数评定：
- 9-10分: "excellent" (优秀)
- 8-8.9分: "high" (高)
- 6-7.9分: "medium" (中)
- 4-5.9分: "low" (低)
- 0-3.9分: "discard" (废弃)

请只输出JSON，不要其他内容。"""
```

### 2.2 评分流程

```
输入 Seed
    ↓
规则预检（快速过滤明显问题）
    ↓
LLM 多维度评分
    ↓
综合计算（加权总分）
    ↓
质量分级
    ↓
输出评分结果
```

### 2.3 批量评分策略

| 批次 | 数量 | 处理方式 | 目的 |
|------|------|---------|------|
| **预检** | 全部 | 规则过滤 | 快速剔除明显问题 |
| **抽检** | 500个 | LLM详细评分 | 建立评分基准 |
| **全量** | 全部 | LLM评分 | 完整评估 |
| **复检** | 低分样本 | 人工+LLM复核 | 校准评分标准 |

## 3. 质量分级标准

### 3.1 四级分级

| 等级 | 分数范围 | 占比目标 | 处理方式 |
|------|---------|---------|---------|
| **优秀 (excellent)** | 9.0-10分 | 20% | 优先使用，高质量训练 |
| **高 (high)** | 8.0-8.9分 | 40% | 正常使用，主要训练数据 |
| **中 (medium)** | 6.0-7.9分 | 30% | 选择性使用，补充数据 |
| **低 (low)** | 4.0-5.9分 | 8% | 谨慎使用，特殊情况 |
| **废弃 (discard)** | 0-3.9分 | 2% | 不使用，过滤掉 |

### 3.2 分级标签

```json

  "quality_level": "high",
  "quality_score": 8.3,
  "usage_recommendation": "recommended",
  "priority": "normal"
}
```

## 4. 规则预检清单

### 4.1 自动过滤规则（0分直接废弃）

| 规则 | 说明 | 处理方式 |
|------|------|---------|
| 长度异常 | 少于5字或超过200字 | discard |
| 敏感词 | 包含政治/色情/违法内容 | discard |
| 无意义 | 纯符号、乱码、无中文 | discard |
| 重复度过高 | 与已有Seed相似度>90% | discard |

### 4.2 降级规则（扣5分）

| 规则 | 说明 | 扣分 |
|------|------|------|
| 编造涨跌 | 出现"一直跌"、"涨得好"等 | compliance -5 |
| 槽位不匹配 | 小白问过于专业的问题 | relevance -5 |
| 信息严重缺失 | 无法确定问的是什么 | completeness -5 |

## 7. 质量控制

### 7.1 评分一致性验证

- 随机抽取 100 个 Seed，用不同 prompt 多次评分
- 标准差 < 0.5 视为评分稳定

### 7.2 人工抽检

- 每个等级抽检 20 个
- 人工评分与 LLM 评分偏差 < 1 分视为合格
