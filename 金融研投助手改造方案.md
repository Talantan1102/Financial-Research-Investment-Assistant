## 📊 AgentFlow 工具架构分析

### 当前架构层次

```
┌─────────────────────────────────────────────────────────────┐
│                    Agent (LLM Controller)                    │
│                   (ReAct Loop / Multi-Agent)                 │
├─────────────────────────────────────────────────────────────┤
│                    Tool Registry                             │
│              (工具注册、参数校验、权限控制)                      │
├─────────────────────────────────────────────────────────────┤
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────────────┐ │
│  │  RAG工具  │ │  Web工具  │ │ GUI工具   │ │   Code工具        │ │
│  │  rag:search│ │ web:search│ │ vm:*     │ │ code:execute     │ │
│  └──────────┘ └──────────┘ └──────────┘ └──────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│                    Sandbox Server (HTTP API)                 │
│              (统一协议、Session管理、资源隔离)                  │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐ ┌─────────────┐ ┌─────────────────────┐    │
│  │ RAGBackend  │ │BrowserBackend│ │ VMBackend           │    │
│  │ (Faiss+E5)  │ │ (Playwright) │ │ (PyAutoGUI)         │    │
│  └─────────────┘ └─────────────┘ └─────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

### 工具调用协议

AgentFlow 使用统一的 HTTP 协议：

```python
# 执行请求格式
{
    "message_type": "execute",
    "action": "rag:search",          # 工具名
    "params": {"query": "...", "top_k": 10},  # 参数
    "session_id": "..."               # Session 上下文
}

# 返回格式
{
    "success": True,
    "result": {...},                   # 工具执行结果
    "observation": "..."               # 自然语言描述
}
```

### 步骤1：创建金融工具 Backend

**文件位置**: `sandbox/server/backends/resources/finance.py`

```python
"""
Finance Backend - 金融数据查询后端
支持行情、财务、宏观、产业链等查询
"""

from typing import Dict, Any, List, Optional
from sandbox.server.backends.base import Backend, BackendConfig
from sandbox.server.tools import register_api_tool


class FinanceBackendConfig(BackendConfig):
    """金融后端配置"""
    tushare_token: str = ""           # Tushare API Token
    tushare_api_url: str = ""         # Tushare API URL
    akshare_enabled: bool = True      # 是否启用 AKShare
    cache_ttl: int = 300              # 缓存时间(秒)


class FinanceBackend(Backend):
    """
    金融数据查询后端
    
    支持的 actions:
    - finance:quote        # 行情查询
    - finance:financial    # 财务指标
    - finance:macro        # 宏观数据
    - finance:industry     # 产业链
    - finance:search       # 信源检索（复用 RAG）
    """
    
    config_class = FinanceBackendConfig
    
    async def initialize(self, config: FinanceBackendConfig):
        """初始化金融数据源"""
        self.config = config
        
        # 初始化 Tushare
        if config.tushare_token:
            import tushare as ts
            ts.set_token(config.tushare_token)
            self.ts_api = ts.pro_api(config.tushare_api_url)
        
        # 初始化 AKShare
        if config.akshare_enabled:
            import akshare as ak
            self.ak_api = ak
        
        # 初始化缓存
        self.cache = {}
    
    # ============ 工具方法 ============
    
    async def action_quote(self, ts_code: str, 
                          start_date: str = None,
                          end_date: str = None) -> Dict[str, Any]:
        """
        查询股票行情
        
        Args:
            ts_code: 股票代码 (如 "000001.SZ")
            start_date: 开始日期 (YYYYMMDD)
            end_date: 结束日期 (YYYYMMDD)
        
        Returns:
            {
                "ts_code": "000001.SZ",
                "name": "平安银行",
                "data": [
                    {"trade_date": "20240314", "open": 10.5, ...},
                    ...
                ]
            }
        """
        # 调用 Tushare API
        df = self.ts_api.daily(ts_code=ts_code, 
                              start_date=start_date,
                              end_date=end_date)
        
        return {
            "ts_code": ts_code,
            "name": self._get_stock_name(ts_code),
            "data": df.to_dict('records')
        }
    
    async def action_financial(self, ts_code: str,
                               report_type: str = "income") -> Dict[str, Any]:
        """
        查询财务指标
        
        Args:
            ts_code: 股票代码
            report_type: 报表类型 (income/balance/cash)
        
        Returns:
            {
                "ts_code": "000001.SZ",
                "report_type": "income",
                "data": [...]
            }
        """
        if report_type == "income":
            df = self.ts_api.income(ts_code=ts_code)
        elif report_type == "balance":
            df = self.ts_api.balancesheet(ts_code=ts_code)
        elif report_type == "cash":
            df = self.ts_api.cashflow(ts_code=ts_code)
        
        return {
            "ts_code": ts_code,
            "report_type": report_type,
            "data": df.to_dict('records')
        }
    
    async def action_macro(self, indicator: str) -> Dict[str, Any]:
        """
        查询宏观经济指标
        
        Args:
            indicator: 指标名称 (gdp/cpi/ppi/pmi)
        
        Returns:
            {
                "indicator": "cpi",
                "data": [...]
            }
        """
        indicator_map = {
            "gdp": self.ts_api.cn_gdp,
            "cpi": self.ts_api.cn_cpi,
            "ppi": self.ts_api.cn_ppi,
            "pmi": self.ts_api.cn_pmi
        }
        
        if indicator not in indicator_map:
            raise ValueError(f"Unknown indicator: {indicator}")
        
        df = indicator_map[indicator]()
        
        return {
            "indicator": indicator,
            "data": df.to_dict('records')
        }
    
    async def action_industry(self, industry_code: str = None,
                             industry_name: str = None) -> Dict[str, Any]:
        """
        查询产业链/行业数据
        
        Args:
            industry_code: 行业代码
            industry_name: 行业名称
        
        Returns:
            {
                "industry_code": "C36",
                "industry_name": "汽车制造业",
                "companies": [...],
                "upstream": [...],
                "downstream": [...]
            }
        """
        # 使用 AKShare 获取产业链数据
        df = self.ak_api.stock_industry_chain(industry_name)
        
        return {
            "industry_code": industry_code,
            "industry_name": industry_name,
            "companies": df.to_dict('records'),
            "upstream": self._get_upstream(industry_name),
            "downstream": self._get_downstream(industry_name)
        }
    
    # ============ 辅助方法 ============
    
    def _get_stock_name(self, ts_code: str) -> str:
        """获取股票名称"""
        df = self.ts_api.stock_basic(ts_code=ts_code)
        return df['name'].iloc[0] if not df.empty else ""
    
    def _get_upstream(self, industry_name: str) -> List[str]:

    def _get_downstream(self, industry_name: str) -> List[str]:
```

### 步骤2：创建信源检索 Backend（扩展 RAG）

**文件位置**: `sandbox/server/backends/resources/finance_rag.py`

```python
"""
Finance RAG Backend - 金融信源检索后端
支持研报、公告、新闻等多源检索 + 信源评级
"""

from typing import Dict, Any, List
from sandbox.server.backends.resources.rag import RAGBackend, RAGBackendConfig


class FinanceRAGBackendConfig(RAGBackendConfig):
    """金融 RAG 配置"""
    source_weights: Dict[str, float] = {    # 信源权重配置
        "official": 1.0,      # 官方公告
        "academic": 0.9,      # 学术论文
        "research": 0.8,      # 券商研报
        "media": 0.6,         # 财经媒体
        "social": 0.3         # 社交媒体
    }
    rating_enabled: bool = True              # 启用信源评级


class FinanceRAGBackend(RAGBackend):
    """
    金融信源检索后端
    
    在标准 RAG 基础上增加：
    - 多信源融合（研报+公告+新闻）
    - 信源评级加权
    - 时效性排序
    """
    
    config_class = FinanceRAGBackendConfig
    
    async def action_search(self, query: str, 
                           top_k: int = 10,
                           source_filter: List[str] = None) -> Dict[str, Any]:
        """
        金融信源检索
        
        Args:
            query: 查询关键词
            top_k: 返回结果数
            source_filter: 信源过滤 (official/research/media/...)
        
        Returns:
            {
                "query": "...",
                "results": [
                    {
                        "content": "...",
                        "source": "券商研报",
                        "source_type": "research",
                        "rating": 0.8,
                        "date": "2024-03-14",
                        "score": 0.95
                    }
                ],
                "total_found": 100
            }
        """
        # 1. 执行基础检索
        base_results = await super().action_search(query, top_k=top_k * 2)
        
        # 2. 信源评级
        rated_results = self._rate_sources(base_results['results'])
        
        # 3. 重新排序（考虑信源评级）
        reranked = self._rerank_by_rating(rated_results)
        
        # 4. 过滤
        if source_filter:
            reranked = [r for r in reranked if r['source_type'] in source_filter]
        
        return {
            "query": query,
            "results": reranked[:top_k],
            "total_found": len(reranked)
        }
    
    def _rate_sources(self, results: List[Dict]) -> List[Dict]:
        """为检索结果添加信源评级"""
        for result in results:
            source_type = result.get('source_type', 'unknown')
            result['rating'] = self.config.source_weights.get(source_type, 0.5)
        return results
    
    def _rerank_by_rating(self, results: List[Dict]) -> List[Dict]:
        """基于信源评级重新排序"""
        # 综合评分 = 语义相似度 * 信源评级 * 时效性因子
        for result in results:
            semantic_score = result.get('score', 0.5)
            rating = result.get('rating', 0.5)
            recency_factor = self._calculate_recency(result.get('date'))
            
            result['final_score'] = semantic_score * rating * recency_factor
        
        return sorted(results, key=lambda x: x['final_score'], reverse=True)
    
    def _calculate_recency(self, date_str: str) -> float:
        """计算时效性因子"""
        from datetime import datetime, timedelta
        
        if not date_str:
            return 0.5
        
        try:
            date = datetime.strptime(date_str, "%Y-%m-%d")
            days_ago = (datetime.now() - date).days
            # 越新越高，30天内1.0，超过90天0.5
            return max(0.5, 1.0 - days_ago / 180)
        except:
            return 0.5
```

## 📝 总结

### 改造成本评估

| 组件 | 工作量 | 难度 |
|------|--------|------|
| FinanceBackend | 2-3天 | ⭐⭐⭐ |
| FinanceRAGBackend | 1-2天 | ⭐⭐ |
| 配置文件 | 0.5天 | ⭐ |
| 测试验证 | 1天 | ⭐⭐ |
| **总计** | **4-6天** | **中等** |

### 优势

1. **复用 AgentFlow 架构**：Session 管理、工具注册、数据合成流程开箱即用
2. **统一协议**：与现有 RAG、Web 等工具无缝集成
3. **可扩展**：后续可方便添加更多金融工具
4. **数据合成**：可利用 AgentFlow 的 trajectory synthesis 生成训练数据

### 与现有金融研投助手的关系

- **现有系统**：面向用户，提供端到端服务
- **AgentFlow 改造**：面向数据合成，生成高质量训练数据
- **两者结合**：用 AgentFlow 合成数据 → 训练模型 → 部署到现有系统
